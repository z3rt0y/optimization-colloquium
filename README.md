# Методы оптимизации — сайт для подготовки к коллоквиуму

Обычный статический сайт: HTML, CSS и JavaScript. Работает в любом браузере без Claude и без регистрации. Интернет нужен только для шрифтов и 3D-графика Армихо (three.js с cdnjs), всё остальное — локально.

## Что где лежит

```
site.json                  ← главное: какие разделы и карточки есть на сайте и в каком порядке
build.py                   ← сборка: python3 build.py → готовый сайт в папке dist/
src/
  partials/hero.html       шапка: заголовок, фильтр билетов, переключатель темы
  partials/cheatsheet.html шпаргалка «всё одной цепочкой» (её дерево рисует js/50-cheatsheet-tree.js)
  partials/intro-notes.html вводные заметки «как устроена карточка», «откуда материал»
  sections/1-minima/d1.html … одна карточка = один файл (d4 — определение № 4, t4 — теорема 4,
  sections/6-proofs/t1.html …   pA1 — задача A1 семинара, pW3 — П3 тетради, pTA — пробный билет А)
  sections/*/_intro.html   вступление раздела (если есть)
  sections/8-workbook/_photos.html  галерея фото тетради и окно просмотра
  css/style.css            все стили, светлая и тёмная тема
  js/00-core.js …          графики и интерактивы; склеиваются по порядку имён
img/                       фото тетради
.github/workflows/deploy.yml  автосборка и выкладка на GitHub Pages
```

## Как убрать часть сайта

1. Открой `site.json`.
2. Найди карточку по имени файла и допиши ей `"off": true` (или просто удали её строку):
   ```json
   { "file": "d4.html", "toc_n": "4", "toc": "Глобальный минимум", "off": true },
   ```
3. Целый раздел убирается так же — `"off": true` у раздела.
4. Шпаргалка и вводные заметки выключаются флагами `"cheatsheet": false` и `"intro_notes": false`. Фото тетради — удали строку `"photos": "_photos.html"` у раздела `workbook`.
5. Пересобери: `python3 build.py`. Если сайт на GitHub, достаточно сохранить изменения — он пересоберётся сам за минуту.

Сборщик сам подчищает хвосты. Пункты оглавления и ссылки в шапке пропадают. Ссылки на убранное из других мест становятся зачёркнутым текстом, а сборка перечисляет, на какие убранные части они вели и сколько их было. Кнопки «Открыть в калькуляторе» на убранный калькулятор и кнопки «фото» без галереи прячутся. Счётчики «Знаю: …» пересчитываются по тому, что осталось.

Вернуть часть — убери `"off": true`. Файлы карточек при выключении не удаляются.

Текст во вводном абзаце шапки («24 определения…», «7 доказательств…») не пересчитывается: если вырежешь много, поправь его руками в `src/partials/hero.html`.

## Как поменять или добавить

- **Текст карточки** — правь её файл в `src/sections/…`. Это обычный HTML; формулы набраны значками Unicode.
- **Новая карточка** — скопируй похожий файл, поменяй `id="…"` внутри (он должен быть уникальным) и добавь строку в `site.json` в нужное место. `toc` — подпись в оглавлении, `toc_n` — номер в оглавлении. Если `toc` не указать, карточки в оглавлении не будет.
- **Порядок** — переставь строки в `site.json`.
- **Плашки «Баулин files» / «Матвеева files»** — подписи в `site.json` → `badges`. Плашки внутри карточек — это `<span class="srcb baulin">` в файлах карточек.
- **Название, описание, подвал** — `title`, `description`, `footer` в `site.json`.
- **Интерактивы** — блок `<div class="widget" data-w="имя">` в карточке подключает функцию `WIDGETS.имя` из `src/js/`. Убрал блок — график пропал, остальное работает.

## Как собрать у себя

Нужен только Python 3, без пакетов:

```
python3 build.py
```

Открой `dist/index.html` двойным кликом. В `dist/` кладутся:

- `index.html` с папками `assets/` и `img/` — то, что выкладывается в сеть;
- `standalone.html` — та же страница одним файлом (CSS и JS внутри). Его можно, например, снова выложить артефактом в Claude, но фото тетради он берёт из соседней папки `img/`.

## Как выложить в сеть

### GitHub Pages — бесплатно, сайт обновляется сам

1. На github.com: **New repository** → придумай имя (например `optimization-colloquium`) → **Public** → **Create repository**.
2. На странице пустого репозитория нажми **uploading an existing file** и перетащи **содержимое** этой папки: `site.json`, `build.py`, `src`, `img`, `README.md`, `.github`. Папку `dist` можно не грузить. На macOS скрытая папка `.github` не видна в Finder; Cmd + Shift + . показывает её. Если она не загрузилась, открой вкладку **Actions** → **set up a workflow yourself**, вставь содержимое `.github/workflows/deploy.yml` и сохрани.
3. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
4. Во вкладке **Actions** дождись зелёной галочки (около минуты). Адрес сайта: `https://ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Дальше любое изменение — прямо на github.com (карандаш у файла → **Commit changes**) — пересобирает и обновляет сайт само.

### Vercel

**Add New → Project** → выбери этот репозиторий → Framework Preset: **Other**, Build Command: `python3 build.py`, Output Directory: `dist` → **Deploy**.

### Netlify Drop — без репозитория

Собери сайт (`python3 build.py`), открой app.netlify.com/drop и перетащи туда папку `dist`. Ссылка появится сразу. Чтобы сайт не удалился, нужен бесплатный аккаунт Netlify. Обновлять придётся тем же перетаскиванием.

## Видимость

Сайт по ссылке открывается у всех. В `site.json` стоит `"noindex": true`: поисковики его не индексируют, найти можно только по ссылке. Учти, что на сайте лежат задачи семинара и фото рабочей тетради преподавателей. Если не хочешь выкладывать их открыто, выключи соответствующие разделы и фото, как описано выше. При GitHub Pages на бесплатном аккаунте открытым будет и сам репозиторий.
