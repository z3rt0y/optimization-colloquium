Выпуклая комбинация и выпуклое множество (convex combination and convex set)

Выпуклая комбинация (convex combination) точек x₁, …, xₘ ∈ ℝᵈ — это

x = θ₁x₁ + … + θₘxₘ,   θᵢ ≥ 0,   θ₁ + … + θₘ = 1.

Множество C ⊆ ℝᵈ выпукло (convex set), если (1 − t)x + ty ∈ C для любых x, y ∈ C и t ∈ [0, 1], то есть вместе с любыми двумя точками C содержит соединяющий их отрезок.

Интуиция

Выпуклая комбинация — взвешенное среднее с неотрицательными весами, дающими в сумме 1; для двух точек это точки отрезка между ними. Выпуклое множество — фигура без вмятин и дыр: натяни нитку между любыми двумя её точками, и нитка нигде не выйдет наружу.

Подробнее

  • Выпуклое множество содержит все выпуклые комбинации любого конечного числа своих точек. Доказывается индукцией по m, тем же приёмом, что и неравенство Йенсена (лекция 2, сл. 21–25).
  • Выпуклые примеры (лекция 2, сл. 5): аффинные подпространства, полупространства aᵀx ≤ b, шары по любой норме, «ящики» (box), вероятностный симплекс Δ = {x : xᵢ ≥ 0, 1ᵀx = 1}.
  • Пересечение любого семейства выпуклых множеств выпукло (теорема 3, доказательство в три шага на сл. 6–8). Поэтому многогранник {x : Ax ≤ b} выпукл: это пересечение полупространств. Объединение выпуклых множеств может быть невыпуклым (два непересекающихся круга).
  • Невыпуклые: кольцо, полумесяц, звезда, решётка ℤⁿ. Последнее объясняет, почему целочисленная оптимизация трудная.

В задачах и в коде

Допустимые множества LP и выпуклых задач — пересечения полупространств и шаров, то есть выпуклы. Веса смеси моделей, выходы softmax и доли портфеля лежат в симплексе; взвешенное усреднение предсказаний нескольких моделей — выпуклая комбинация.

import numpy as np

pts = np.array([[0.0, 0.0], [4.0, 0.0], [0.0, 4.0]])
theta = np.array([0.5, 0.25, 0.25])
in_simplex = np.all(theta >= 0) and np.isclose(theta.sum(), 1)
print(in_simplex, theta @ pts)
# True [1. 1.]

Посчитай руками

1) Найди выпуклую комбинацию точек A(0, 0), B(4, 0), C(0, 4) с весами θ = (0.5, 0.25, 0.25). 2) Докажи, что кольцо K = {x : 1 ≤ ‖x‖ ≤ 2} невыпукло.

Решение

1) x = 0.5·(0, 0) + 0.25·(4, 0) + 0.25·(0, 4) = (1, 1). Точка лежит в треугольнике ABC, как и любая выпуклая комбинация его вершин.

2) Возьмём x = (−1.5, 0) и y = (1.5, 0): ‖x‖ = ‖y‖ = 1.5, обе точки в K. При t = 0.5 получаем (0, 0), ‖(0, 0)‖ = 0 < 1, точка вне K. Нашёлся отрезок, выходящий из множества, значит K невыпукло.

Поиграй

Выбери множество и тащи концы отрезка A и B. Красные куски отрезка вне множества. «Найти контрпример» перебирает тысячи пар точек; для выпуклых множеств он ничего не найдёт. В режиме «3 точки» двигай веса θ.
