Строго выпуклая и µ-сильно выпуклая функция (strictly convex and µ-strongly convex function)

Colab: для проверкиЛекция 2, сл. 9–10, 16, 32 · Renegar §1.4
На коллоквиуме · 0.5 балла нажми, чтобы открыть

Пусть C выпукло, f: C → ℝ.

  • f строго выпукла (strictly convex), если f((1 − t)x + ty) < (1 − t)f(x) + t f(y) для всех x ≠ y из C и t ∈ (0, 1).
  • f µ-сильно выпукла (µ-strongly convex), µ > 0, если для всех x, y ∈ C, t ∈ [0, 1]:
f((1 − t)x + ty) ≤ (1 − t)f(x) + t f(y) − (µ/2)·t(1 − t)·‖x − y‖².

Сильная выпуклость ⇒ строгая ⇒ обычная; обратные импликации неверны.

Интуиция

Строгая: хорда лежит строго выше графика, нигде нет прямолинейных кусков. Сильная: график изогнут не слабее параболы (µ/2)x². Хорду можно опустить на «запас» (µ/2)t(1 − t)‖x − y‖², и она всё равно останется над графиком.

Подробнее

  • Эквивалентные формы для дифференцируемой f (лекция 2, сл. 32): f(y) ≥ f(x) + ∇f(x)ᵀ(y − x) + (µ/2)‖y − x‖² — нижняя квадратичная модель. Для f ∈ C²: ∇²f(x) ⪰ µI всюду (лекция 2, теорема 10). Ещё одна: функция f − (µ/2)‖x‖² выпукла.
  • Следствия: не более одного минимизатора; квадратичный рост f(x) − f⋆ ≥ (µ/2)‖x − x⋆‖²; выполнено условие PL с тем же µ (№ 16); определено число обусловленности κ = L/µ (№ 15).
  • Таблица из лекции 2, сл. 10: |x| выпукла, но не строго; x⁴ строго, но не сильно на ℝ (f″ = 12x² → 0 у нуля); ½x² 1-сильно выпукла; eˣ строго, но не сильно на ℝ (f″ = eˣ → 0 при x → −∞); константа только выпукла.
  • ∇²f ≻ 0 всюду ⇒ строгая выпуклость (Renegar, Prop. 1.4.1), обратное неверно: у x⁴ в нуле f″ = 0.

В задачах и в коде

L2-регуляризация делает задачу сильно выпуклой: f(w) + (λ/2)‖w‖² сильно выпукла с µ ≥ λ. Отсюда единственность решения ridge-регрессии и линейная сходимость GD (теорема билетов 1, 12, 16). Для квадратичной задачи µ — минимальное собственное значение гессиана:

import numpy as np

rng = np.random.default_rng(0)
x = rng.normal(size=(50, 80))
h = x.T @ x / len(x)
print(np.linalg.eigvalsh(h).min())
lam = 0.5
print(np.linalg.eigvalsh(h + lam * np.eye(80)).min())
# -9.8e-16 ← 80 признаков на 50 объектов: µ = 0, сильной выпуклости нет # 0.5 ← после ridge µ = λ

Посчитай руками

1) Найди наибольшее µ для f(x) = 2x² + 3x. 2) Сильно выпукла ли x⁴ на ℝ? А на [1, 2]? 3) Для f(x, y) = x² + 3y² + xy найди µ и L.

Решение

1) f″ = 4 ⇒ f″ ≥ 4, наибольшее µ = 4.

2) На ℝ нет: inf 12x² = 0, ни одно µ > 0 не подходит. На [1, 2]: f″ = 12x² ≥ 12 ⇒ 12-сильно выпукла.

3) ∇²f = [[2, 1], [1, 6]], след 8, определитель 11, собственные значения 4 ± √5 ≈ 1.76 и 6.24. Значит µ = 4 − √5 ≈ 1.76, L = 4 + √5 ≈ 6.24, κ ≈ 3.54.

Поиграй

Сверху f и нижняя квадратичная модель в точке x₀ с параметром µ: если модель где-то выше графика (красное), такое µ не годится. Снизу f″ и уровень µ. Сузь окно, чтобы увидеть, что x⁴ сильно выпукла на [1, 2].
