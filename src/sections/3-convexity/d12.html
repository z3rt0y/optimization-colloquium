Выпуклая функция (convex function)

Colab: для проверкиЛекция 1, сл. 15 · Лекция 2, сл. 9–25 · Renegar §1.4
На коллоквиуме · 0.5 балла нажми, чтобы открыть

Пусть C ⊆ ℝⁿ выпукло. Функция f: C → ℝ выпукла (convex function), если

f((1 − t)x + ty) ≤ (1 − t)f(x) + t f(y) для всех x, y ∈ C, t ∈ [0, 1].

Интуиция

Хорда между любыми двумя точками графика лежит не ниже графика. Значение функции в среднем не больше среднего значений.

Подробнее

  • Критерий 1-го порядка (first-order characterization, теорема билетов 4, 11, 14; лекция 2, сл. 11–15): для дифференцируемой f на открытом выпуклом C: f выпукла ⇔ f(y) ≥ f(x) + ⟨∇f(x), y − x⟩ для всех x, y. Касательная плоскость всюду лежит под графиком.
  • Критерий 2-го порядка (second-order characterization, теорема билетов 2, 13, 18; лекция 2, сл. 16–20; Renegar, Prop. 1.4.1): для f ∈ C²: f выпукла ⇔ ∇²f(x) ⪰ 0 для всех x ∈ C.
  • Неравенство Йенсена (Jensen's inequality, лекция 2, сл. 21): f(Σθᵢxᵢ) ≤ Σθᵢf(xᵢ); вероятностная форма f(EX) ≤ Ef(X).
  • Главное следствие (лекция 2, сл. 3): у дифференцируемой выпуклой f каждая стационарная точка — глобальный минимум.
  • Область определения обязана быть выпуклой: иначе точка (1 − t)x + ty может из неё выпасть, и определение теряет смысл.

В задачах и в коде

Квадратичная ошибка (MSE), логистическая потеря (log-loss), hinge loss, нормы, L1- и L2-регуляризация выпуклы. Поэтому для линейных моделей градиентный спуск приходит к глобальному оптимуму. Численно выпуклость можно только опровергнуть (найти хорду под графиком), но не доказать:

import numpy as np

def f(x):
    return np.log(1 + np.exp(x))

rng = np.random.default_rng(1)
worst = np.inf
for i in range(10000):
    x = rng.uniform(-5, 5)
    y = rng.uniform(-5, 5)
    t = rng.uniform(0, 1)
    gap = (1 - t) * f(x) + t * f(y) - f((1 - t) * x + t * y)
    worst = min(worst, gap)
print(worst)
# 1.16e-10 ← ни одной хорды ниже графика: контрпримера к выпуклости нет

Посчитай руками

1) Проверь определение для f(x) = x² при x = −1, y = 3, t = 0.25. 2) Покажи, что sin x на [0, π] невыпукла. 3) Что даёт критерий 1-го порядка для eˣ в точке 0?

Решение

1) (1 − t)x + ty = −0.75 + 0.75 = 0 ⇒ левая часть f(0) = 0; правая 0.75·1 + 0.25·9 = 3; 0 ≤ 3 ✓. Разница 3 = t(1 − t)(x − y)² = 0.1875·16; для x² это тождество.

2) x = 0, y = π, t = 0.5: sin(π/2) = 1, а (sin 0 + sin π)/2 = 0. Хорда ниже графика ⇒ невыпукла (на [0, π] она вогнута).

3) Касательная к eʸ в нуле: 1 + y. Критерий 1-го порядка даёт eʸ ≥ 1 + y для всех y, и это верно, так как (eʸ)″ = eʸ > 0.

Поиграй

Тащи точки x и y (кружки на графике), ползунок t двигает точку по хорде. Зелёный зазор — определение выполнено, красный — нарушено. Включи касательную, чтобы проверить критерий 1-го порядка. Нижний график — f″ (критерий 2-го порядка).
