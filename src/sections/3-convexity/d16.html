Условие Поляка–Лоясевича (Polyak–Łojasiewicz condition)

Colab: для проверкиЛекция 2, сл. 33–38 · Лекция 3, сл. 15
На коллоквиуме · 0.5 балла нажми, чтобы открыть

Дифференцируемая f удовлетворяет условию Поляка–Лоясевича (Polyak–Łojasiewicz, PL) с константой µ > 0, если

½‖∇f(x)‖² ≥ µ (f(x) − f⋆) для всех x,   где f⋆ = inf f.

Интуиция

Если ты далеко от оптимального значения, градиент обязан быть большим. Значит, нет плоских плато и «ложных» стационарных точек: ∇f(x) = 0 сразу даёт f(x) = f⋆. При этом PL ничего не требует от формы множества минимумов: это может быть прямая, кривая, несколько кусков.

Подробнее

  • µ-сильная выпуклость ⇒ PL с тем же µ (доказательство в 4 шага, лекция 2, сл. 34–37: минимизируем по y нижнюю квадратичную модель).
  • PL строго слабее (лекция 2, сл. 38): f(x, y) = x² удовлетворяет PL с µ = 2, но ∇²f = diag(2, 0) вырожден, и минимумов целая прямая (0, y).
  • PL не требует выпуклости: f(x) = x² + 3sin²x невыпукла (f″(π/2) = 2 − 6 = −4 < 0), но удовлетворяет PL; численно µ ≈ 0.175.
  • Теорема (лекция 3, сл. 15): для L-гладкой f с условием PL GD с α = 1/L сходится линейно, f(xₖ) − f⋆ ≤ (1 − µ/L)ᵏ (f(x₀) − f⋆). Выпуклость в доказательстве не используется.

В задачах и в коде

Недоопределённый МНК (признаков больше, чем объектов): решений бесконечно много, XᵀX вырождена, сильной выпуклости нет, а PL выполнено с µ, равным наименьшему ненулевому собственному значению XᵀX/N. Поэтому GD и там сходится линейно. Есть работы, где локальным условием PL объясняют быструю сходимость обучения широких нейросетей. Константу в 1D можно оценить на сетке:

import numpy as np

xs = np.linspace(-20, 20, 2000001)
xs = xs[np.abs(xs) > 1e-6]
f = xs**2 + 3 * np.sin(xs)**2
g = 2 * xs + 3 * np.sin(2 * xs)
print((0.5 * g**2 / f).min())
# 0.1755

Посчитай руками

1) Найди наибольшую PL-константу для f(x) = 3x². 2) Проверь PL для f(x, y) = x². 3) Почему x⁴ не удовлетворяет PL?

Решение

1) f⋆ = 0; ½(6x)² = 18x² ≥ µ·3x² ⇔ µ ≤ 6 ⇒ µ = 6 (совпадает с f″ = 6).

2) ∇f = (2x, 0), ½‖∇f‖² = 2x² = 2(f − f⋆) ⇒ µ = 2.

3) ½(4x³)²/x⁴ = 8x² → 0 при x → 0, никакое µ > 0 не подходит. Около минимума градиент слишком мал, и GD на x⁴ сходится сублинейно.

Поиграй

Сверху функция и итерации GD с α = 1/L (запусти «Пуск»). Снизу отношение ½f′²/(f − f⋆): PL с константой µ выполнено там, где кривая выше линии µ. Для невыпуклой x² + 3sin²x отношение нигде не падает до нуля, и GD сходится линейно.
