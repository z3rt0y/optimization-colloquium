L-гладкость (L-smoothness, Lipschitz gradient)

Colab: напрямуюЛекция 2, сл. 26–31 · Лекция 3, сл. 7–8
На коллоквиуме · 0.5 балла нажми, чтобы открыть

Дифференцируемая f называется L-гладкой (L-smooth) на C, если её градиент L-липшицев (Lipschitz gradient):

‖∇f(x) − ∇f(y)‖ ≤ L‖x − y‖ для всех x, y ∈ C.

Для f ∈ C² достаточно ‖∇²f(x)‖₂ ≤ L; для квадратичной ½xᵀQx + bᵀx можно взять L = λmax(Q).

Интуиция

Градиент не может меняться слишком резко, то есть кривизна ограничена сверху. В каждой точке график лежит под параболой «раствора» L, касающейся его в этой точке. Эта парабола и говорит, какой шаг безопасен.

Подробнее

  • Лемма о спуске (descent lemma, теорема билетов 17, 19, 20; лекция 2, сл. 27–31): f(y) ≤ f(x) + ∇f(x)ᵀ(y − x) + (L/2)‖y − x‖² — верхняя квадратичная модель.
  • Следствие для шага GD (лекция 3, сл. 8): f(x⁺) ≤ f(x) − α(1 − Lα/2)‖∇f(x)‖². Убывание гарантировано при 0 < α < 2/L; при α = 1/L: f(x⁺) ≤ f(x) − ‖∇f(x)‖²/(2L), это минимум верхней модели.
  • Вместе с µ-сильной выпуклостью получается «сэндвич» µI ⪯ ∇²f ⪯ LI: функция зажата между двумя параболами.
  • L-гладкость не требует выпуклости (sin x 1-гладкая) и не следует из неё (x⁴ выпукла, но на ℝ не L-гладкая).

В задачах и в коде

L задаёт безопасный шаг обучения: learning rate около 1/L. Для МНК L = λmax(XᵀX/N), для логистической регрессии L ≤ λmax(XᵀX)/(4N), потому что σ′ ≤ 1/4. Вот что происходит с шагом за границей 2/L:

import numpy as np

rng = np.random.default_rng(0)
x = rng.normal(size=(200, 3)) * np.array([1.0, 3.0, 0.5])
y = x @ np.array([1.0, -2.0, 0.5])
h = x.T @ x / len(x)
lip = np.linalg.eigvalsh(h).max()
for alpha in [1 / lip, 2.1 / lip]:
    w = np.zeros(3)
    for i in range(100):
        w = w - alpha * (h @ w - x.T @ y / len(x))
    print(alpha * lip, np.linalg.norm(w))
# 1.0 2.28 ← сходится к ‖(1, −2, 0.5)‖ ≈ 2.29 # 2.1 27666.9 ← шаг больше 2/L: разлёт

Посчитай руками

Найди L: 1) для f(x) = 2x²; 2) для softplus f(x) = ln(1 + eˣ); 3) L-гладка ли x⁴ на ℝ? А на [−1, 1]?

Решение

1) |f′(x) − f′(y)| = |4x − 4y| = 4|x − y| ⇒ L = 4.

2) f′ = σ(x) = 1/(1 + e⁻ˣ), f″ = σ(1 − σ) ≤ 1/4 (максимум при σ = 1/2) ⇒ L = 1/4.

3) f″ = 12x² не ограничена на ℝ ⇒ не L-гладкая. На [−1, 1]: |f″| ≤ 12 ⇒ L = 12.

Поиграй

Сверху f и верхняя парабола из леммы о спуске в точке x₀. Если L мало, f где-то вылезает над параболой (красное). Вершина параболы — шаг GD с α = 1/L; сравни гарантированное убывание с настоящим. Снизу |f″| и уровень L.
