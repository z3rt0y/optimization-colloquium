Число обусловленности (condition number)

Для µ-сильно выпуклой и L-гладкой функции число обусловленности (condition number)

κ = L / µ ≥ 1.

Для квадратичной f(x) = ½xᵀQx − bᵀx, Q ≻ 0: κ = λmax(Q)/λmin(Q). Для матрицы в линейной алгебре cond(A) = ‖A‖·‖A⁻¹‖; у симметричной Q ≻ 0 это то же отношение собственных значений.

Интуиция

Насколько вытянута «долина» функции. При κ = 1 чаша круглая, и антиградиент смотрит прямо в минимум. При κ = 1000 это узкий длинный овраг: антиградиент направлен почти поперёк, GD скачет от стенки к стенке (зигзаг) и медленно ползёт вдоль дна.

Подробнее

  • GD с α = 1/L уменьшает ошибку с множителем 1 − 1/κ за шаг, нужно порядка O(κ log(1/ε)) итераций (лекция 3, сл. 16).
  • Лучший постоянный шаг для квадратичной: α* = 2/(L + µ), множитель (κ − 1)/(κ + 1) (лекция 4, сл. 4).
  • Тяжёлый шар Поляка и сопряжённые градиенты (лекция 4, сл. 7, 15) дают (√κ − 1)/(√κ + 1): зависимость от √κ вместо κ.
  • κ меняется при замене координат. Масштабирование признаков (feature scaling) и предобусловливание (preconditioning) уменьшают κ ещё до запуска оптимизатора (лекция 4, сл. 19). Метод Ньютона к κ нечувствителен (№ 20).

В задачах и в коде

Стандартизация признаков перед градиентным обучением, диагностика мультиколлинеарности в регрессии, точность решения линейных систем (при cond ≈ 10ᵏ теряется около k знаков). В Colab — np.linalg.cond и оценка числа итераций:

import numpy as np

q = np.diag([1.0, 100.0])
print(np.linalg.cond(q))
kappa = 100
for rho in [1 - 1 / kappa, (kappa - 1) / (kappa + 1)]:
    print(rho, np.log(1e6) / -np.log(rho))
# 100.0 # 0.99 1374.6 ← α = 1/L # 0.9802 690.8 ← α* = 2/(L + µ)

Посчитай руками

Q = diag(1, 100). Найди κ и оцени, сколько итераций нужно, чтобы ошибка уменьшилась в 10⁶ раз: а) GD с α = 1/L; б) GD с α* = 2/(L + µ); в) тяжёлый шар.

Решение

µ = 1, L = 100, κ = 100. Из ρᵏ ≤ 10⁻⁶ получаем k ≥ ln 10⁶ / (−ln ρ), ln 10⁶ ≈ 13.82.

а) ρ = 1 − 1/100 = 0.99 ⇒ k ≈ 13.82/0.01005 ≈ 1375. б) ρ = 99/101 ≈ 0.9802 ⇒ k ≈ 691. в) ρ = (10 − 1)/(10 + 1) = 9/11 ≈ 0.818 ⇒ k ≈ 69, в 20 раз меньше, чем в а).

Поиграй

Для квадратичной функции каждая собственная компонента ошибки за шаг умножается на |1 − αλ|. Полоса — спектр [µ, L], худший множитель ρ(α) отмечен точкой. Подбирай α и κ: минимум ρ получается при α = 2/(L + µ), а при α ≥ 2/L метод расходится.
