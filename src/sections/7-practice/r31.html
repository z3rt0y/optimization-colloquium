Рецепт · задача 3.1

Как найти стационарную точку и её тип (stationary point of a quadratic form)

Баулин filesColab: напрямуюсеминар 7, блок A
Алгоритм для f(x, y) = ax² + bxy + cy² + dx + ey нажми, чтобы открыть
  1. Градиент и гессиан. ∇f = (2ax + by + d,  bx + 2cy + e), гессиан постоянный: H = [[2a, b], [b, 2c]].
  2. Стационарная точка. Решаем Hx⋆ = −(d, e). При det H ≠ 0 решение единственное. Проверка подстановкой: ∇f(x⋆) = 0.
  3. Собственные значения. λ² − (tr H)λ + det H = 0, где tr H = 2a + 2c, det H = 4ac − b².
  4. Тип. det < 0 ⇒ седло (сразу, без λ). det > 0, tr > 0 ⇒ минимум. det > 0, tr < 0 ⇒ максимум. det = 0 ⇒ вырожденный случай.
  5. Константы. Для минимума µ = λmin, L = λmax, κ = L/µ. Для седла µ и κ не определены.

Ловушки

  • На диагонали H стоят 2a и 2c, а вне диагонали b (не 2b и не b/2): ∂²(bxy)/∂x∂y = b.
  • Правая часть системы — минус линейные коэффициенты: Hx⋆ = −(d, e), потому что ∇f(0) = (d, e).
  • Знак det решает почти всё: для типа не обязательно считать λ, но µ и L требуют корней квадратного уравнения.

В коде

Функция, которую семинар предлагает написать для самопроверки (задание H3):

import numpy as np


def stationary(a, b, c, d, e):
    h = np.array([[2 * a, b], [b, 2 * c]], dtype=float)
    x_star = np.linalg.solve(h, -np.array([d, e], dtype=float))
    lam = np.linalg.eigvalsh(h)
    if lam[0] > 0:
        kind = "минимум"
    elif lam[1] < 0:
        kind = "максимум"
    else:
        kind = "седло"
    return {"x_star": x_star, "lam": lam, "kind": kind}


res = stationary(2, 2, 3, -8, -2)
print(res["x_star"], res["lam"], res["kind"])
# [ 2.2 -0.4] [2.76393202 7.23606798] минимум
