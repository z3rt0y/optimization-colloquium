Как сделать три шага GD на квадратичной функции (gradient descent on a quadratic)

Баулин filesColab: напрямуюсеминар 7, блок B
Алгоритм нажми, чтобы открыть
  1. Запиши f = ½xᵀQx. Если f = ax² + bxy + cy², то Q = [[2a, b], [b, 2c]] (это гессиан).
  2. Шаг. ∇f(x) = Qx, xₖ₊₁ = xₖ − αQxₖ = (I − αQ)xₖ. Удобно один раз посчитать матрицу I − αQ и умножать на неё.
  3. Три раза: на каждом шаге запиши ∇f(xₖ), xₖ₊₁, f(xₖ₊₁). Значение f проверяй подстановкой в исходную формулу.
  4. Проверка шага. L = λmax(Q), нужно строго 0 < α < 2/L. В собственном базисе каждая компонента умножается на 1 − αλᵢ: |·| < 1 — сходимость, = 1 — колебания, > 1 — разлёт.

Что полезно знать

  • Ловушка с ½: f = x² − xy + y² ⇒ Q = [[2, −1], [−1, 2]], а не [[1, −½], [−½, 1]].
  • α = 1/L обнуляет самую крутую компоненту за один шаг (B1, B2). Дальше скорость задаёт пологая компонента: множитель 1 − µ/L = 1 − 1/κ.
  • Знак α − 2/L решает, будет ли разлёт. Величина α − 1/L решает, какая ось задаёт скорость.
  • Сколько шагов нужно, чтобы уменьшить ошибку в 10 раз: при лучшем шаге 2/(L + µ) для κ = 1, 10, 100 это 1, 12 и 116 шагов (так на сайте); при α = 1/L — 1, 22 и 230.

В коде

import numpy as np


def gd_steps(a, b, c, x0, alpha, n=3):
    q = np.array([[2 * a, b], [b, 2 * c]], dtype=float)
    x = np.array(x0, dtype=float)
    for i in range(n):
        g = q @ x
        x = x - alpha * g
        print(i + 1, g, x, 0.5 * x @ q @ x)
    lip = np.linalg.eigvalsh(q).max()
    print("L =", lip, "2/L =", 2 / lip, "безопасно:", alpha < 2 / lip)


gd_steps(1, -1, 1, [6, 0], 1 / 3)
