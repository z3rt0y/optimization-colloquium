A1 · у доски

Стационарная точка и тип квадратичной формы (stationary point and type)

Баулин filesзадача 3.1
Условие

Для f(x, y) = 2x² + 2xy + 3y² − 8x − 2y найди стационарную точку и её тип. Затем найди µ и L как наименьшее и наибольшее собственные значения гессиана.

Подсказка

Для f = ax² + bxy + cy² + dx + ey градиент (2ax + by + d, bx + 2cy + e), гессиан [[2a, b], [b, 2c]].

Решение
  1. 1

    ∇f = (4x + 2y − 8, 2x + 6y − 2), H = [[4, 2], [2, 6]].

  2. 2

    Система ∇f = 0: 4x + 2y = 8, 2x + 6y = 2. det H = 24 − 4 = 20 ≠ 0 ⇒ решение единственное. Из второго x = 1 − 3y; подставляем: 4 − 12y + 2y = 8 ⇒ y = −0.4, x = 2.2. Проверка: ∇f(2.2, −0.4) = (8.8 − 0.8 − 8, 4.4 − 2.4 − 2) = (0, 0) ✓, f(x⋆) = −8.4.

  3. 3

    λ² − 10λ + 20 = 0 ⇒ λ = 5 ± √5: λmin ≈ 2.7639, λmax ≈ 7.2361. Оба положительны ⇒ строгий минимум. Он глобальный: f строго выпукла (№ 13).

  4. 4

    µ ≈ 2.7639, L ≈ 7.2361, κ = (5 + √5)/(5 − √5) ≈ 2.618. GD с лучшим постоянным шагом 2/(L + µ) сжимает ошибку в (κ − 1)/(κ + 1) = 1/√5 ≈ 0.4472 раза за шаг (№ 15).

Ответ: минимум в (2.2, −0.4); µ ≈ 2.7639, L ≈ 7.2361.

Приём: сначала посчитай det и tr, они дают оба λ через λ² − tr·λ + det = 0.
