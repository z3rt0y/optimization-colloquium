B1 · у доски

Три шага градиентного спуска на квадратичной функции (three steps of GD)

Баулин filesзадача 3.2
Условие

Пусть f(x, y) = x² − xy + y². Из x₀ = (6, 0) сделай три шага градиентного спуска с α = 0.3333 (то есть 1/3). Запиши градиенты, x₁, x₂, x₃ и значения f. Найди L и проверь, что α < 2/L.

Подсказка

∇f = Qx, Q = [[2a, b], [b, 2c]]; шаг x⁺ = (I − αQ)x.

Решение
  1. 1

    Q = [[2, −1], [−1, 2]], ∇f = (2x − y, −x + 2y). При α = 1/3: I − αQ = [[1/3, 1/3], [1/3, 1/3]], то есть x⁺ = ((x + y)/3, (x + y)/3).

  2. k = 0

    ∇f(6, 0) = (12, −6); x₁ = (6 − 4, 0 + 2) = (2, 2); f(x₁) = 4 − 4 + 4 = 4.

  3. k = 1

    ∇f(2, 2) = (2, 2); x₂ = (4/3, 4/3) ≈ (1.3333, 1.3333); f(x₂) = 16/9 ≈ 1.7778.

  4. k = 2

    ∇f(x₂) = (4/3, 4/3); x₃ = (8/9, 8/9) ≈ (0.8889, 0.8889); f(x₃) = 64/81 ≈ 0.7901. Значения f: 36 → 4 → 1.7778 → 0.7901.

  5. L

    λ² − 4λ + 3 = 0 ⇒ λ = 1 и 3 ⇒ L = 3, 2/L ≈ 0.6667 > α ⇒ шаг безопасен. Более того, α = 1/3 = 1/L.

  6. Почему так

    Разложим старт по собственным векторам: x₀ = 3·(1, 1) + 3·(1, −1). Компонента с λ = 3 умножается на 1 − 3α = 0 и исчезает за первый шаг, поэтому x₁ лежит на диагонали. Компонента с λ = 1 каждый шаг умножается на 1 − α = 2/3: x₃ = 3·(2/3)³·(1, 1) = (8/9, 8/9) ✓. Отношение ‖x₃‖/‖x₀‖ = (8√2/9)/6 ≈ 0.2095.

Ответ: f(x₁) = 4, f(x₃) ≈ 0.7901; L = 3, условие α < 2/L выполнено.

Если взять α = 0.3333 буквально, числа разойдутся в 4-м знаке (f(x₁) ≈ 4.0004). На листе пиши α = 1/3.
