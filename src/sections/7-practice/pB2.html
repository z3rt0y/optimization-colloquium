Три шага на диагональной квадратичной функции (diagonal quadratic)

Баулин filesзадача 3.2
Условие

Пусть f(x, y) = 3x² + 2y². Из x₀ = (4, −3) сделай три шага градиентного спуска с α = 0.1667 (то есть 1/6). Найди f(x₁), f(x₃), L и проверь, безопасен ли шаг.

Подсказка

Q диагональна, координаты не связаны: множители 1 − 2αa и 1 − 2αc.

Решение
  1. 1

    Q = diag(6, 4); множители 1 − 6α = 0 по x и 1 − 4α = 1/3 по y.

  2. k = 0

    ∇f(x₀) = (24, −12); x₁ = (4 − 4, −3 + 2) = (0, −1); f(x₁) = 2. Координата x исчезла за один шаг.

  3. k = 1, 2

    ∇f(x₁) = (0, −4), x₂ = (0, −1/3), f = 2/9 ≈ 0.2222. ∇f(x₂) = (0, −4/3), x₃ = (0, −1/9), f = 2/81 ≈ 0.0247.

  4. L

    µ = 4, L = 6, 2/L = 1/3 > α ⇒ шаг безопасен. При этом α = 1/L: крутая ось обнуляется сразу, пологая сжимается в 3 раза за шаг.

Исправление к сайту. Там ‖x₃‖/‖x₀‖ = 0.0222 приравнено к (1 − 2αc)³. Но (1/3)³ ≈ 0.037: это отношение |y₃|/|y₀| = (1/9)/3. Отношение норм (1/9)/5 ≈ 0.0222 меньше, потому что у x₀ была ещё x-компонента, которая исчезла на первом шаге.

Ответ: f(x₁) = 2, f(x₃) ≈ 0.0247; L = 6, α < 2/L выполнено.
