Локальный минимум (local minimum)

Colab: напрямуюЛекция 1, сл. 12, 17–18
На коллоквиуме · 0.5 балла нажми, чтобы открыть

Точка x* ∈ Ω — локальный минимум (local minimum) функции f на Ω, если существует ε > 0 такое, что

f(x) ≥ f(x*) для всех x ∈ Ω с ‖x − x*‖ < ε.

Интуиция

Стоишь в ямке: если отойти совсем недалеко (меньше чем на ε), ниже не станет. Что творится дальше, неважно: за холмом может быть яма глубже. Ключевой квантор — «существует ε»: хватает хоть какой-то маленькой окрестности.

Подробнее

  • Окрестность пересекается с Ω: на границе сравниваем только с допустимыми точками. Поэтому x = −3 для x³ − 3x на [−3, 3] — локальный минимум, хотя f′(−3) = 24 ≠ 0 (№ 4).
  • Необходимое условие 1-го порядка (first-order necessary condition, сл. 17): если x* — локальный минимум, то dᵀ∇f(x*) ≥ 0 для любого допустимого направления d (№ 9). Во внутренней точке это ∇f(x*) = 0.
  • Необходимое условие 2-го порядка (сл. 18): во внутренней точке ещё и dᵀ∇²f(x*)d ≥ 0 для всех d, то есть ∇²f(x*) ⪰ 0.
  • Эти условия не достаточны: у f(x) = x³ в нуле f′ = f″ = 0, а минимума нет. В виджете выбери «x³» и проверь.

В задачах и в коде

Градиентные методы (№ 18) гарантированно находят только стационарные точки, в лучшем случае локальные минимумы. Нейросети, k-means и EM сходятся к локальным минимумам, и результат зависит от стартовой точки. Стандартный приём в Colab — мультистарт (multi-start): запустить оптимизатор из нескольких точек и взять лучший ответ.

import numpy as np
from scipy.optimize import minimize

def f(x):
    return x[0]**4 - 3 * x[0]**2 + x[0]

for x0 in [-2.0, 0.5, 2.0]:
    res = minimize(f, x0=np.array([x0]))
    print(x0, res.x[0], res.fun)
# -2.0 -1.3008 -3.5139 ← глобальный # 0.5 1.1309 -1.0702 ← только локальный # 2.0 1.1309 -1.0702

Посчитай руками

Найди локальные минимумы f(x) = x³ − 3x на ℝ. Есть ли глобальный минимум?

Решение

f′(x) = 3x² − 3 = 0 ⇒ x = ±1. f″(x) = 6x.

f″(1) = 6 > 0 ⇒ x = 1 — строгий локальный минимум, f(1) = −2. f″(−1) = −6 < 0 ⇒ x = −1 — локальный максимум.

Глобального минимума на ℝ нет: f(x) → −∞ при x → −∞. Локальный минимум существует, глобального нет, и это нормально.

Поиграй

Выбери точку x* (ползунком или нажатием на график) и радиус ε. Синяя полоса — окрестность. Если внутри неё есть точки ниже f(x*), они подсвечиваются красным, и определение нарушено. Кнопка притягивает x* к ближайшему настоящему минимуму.
