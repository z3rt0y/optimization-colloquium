Строгий локальный минимум (strict local minimum)

Colab: для проверкиЛекция 1, сл. 12, 19
На коллоквиуме · 0.5 балла нажми, чтобы открыть

Точка x* ∈ Ω — строгий локальный минимум (strict local minimum), если существует ε > 0 такое, что

f(x) > f(x*) для всех x ∈ Ω, x ≠ x*, ‖x − x*‖ < ε.

То есть в определении локального минимума нестрогое ≥ заменено на строгое > для всех точек окрестности, кроме самой x*.

Интуиция

Дно ямки — единственная точка. У нестрогого минимума дно плоское: плато или жёлоб, и рядом есть точки с тем же значением.

Подробнее

  • Достаточное условие 2-го порядка (second-order sufficient condition, теорема билетов 3, 8, 15; лекция 1, сл. 19): если ∇f(x*) = 0 и ∇²f(x*) ≻ 0 (№ 10), то x* — строгий локальный минимум.
  • Это условие не необходимое: у x⁴ в нуле строгий минимум, хотя f″(0) = 0.
  • Нестрогие примеры: константа; max(0, |x| − 1)² — минимум в каждой точке [−1, 1]; f(x, y) = x² — минимумы на всей прямой x = 0 (этот пример есть в лекции 2 про условие PL, № 16).
  • Строго выпуклая функция (№ 13) имеет не более одного минимизатора (Renegar §1.4), и он автоматически строгий.

В задачах и в коде

Строгость означает, что решение единственное хотя бы локально. Пример — линейная регрессия с коллинеарными признаками: XᵀX вырождена, минимумы образуют прямую, коэффициенты неидентифицируемы. Ridge-регуляризация добавляет λI к гессиану и делает минимум строгим. В Colab это видно по собственным значениям гессиана:

import numpy as np

rng = np.random.default_rng(0)
a = rng.normal(size=100)
x = np.column_stack([a, 2 * a])
h = x.T @ x / len(x)
print(np.linalg.eigvalsh(h))
lam = 0.1
print(np.linalg.eigvalsh(h + lam * np.eye(2)))
# [0. 4.6614] ← нулевое собственное значение: минимум нестрогий # [0.1 4.7614] ← после ridge все > 0: минимум строгий

Посчитай руками

1) f(x, y) = x² + xy + y² − 3x. Найди стационарную точку и проверь достаточное условие. 2) f(x, y) = (x − y)². Строгий ли у неё минимум?

Решение

1) ∇f = (2x + y − 3, x + 2y) = 0 ⇒ x = −2y, −4y + y = 3 ⇒ y = −1, x = 2. ∇²f = [[2, 1], [1, 2]], собственные значения 1 и 3 > 0 ⇒ ∇²f ≻ 0 ⇒ (2, −1) — строгий локальный минимум, f = 4 − 2 + 1 − 6 = −3.

2) ∇f = (2(x − y), −2(x − y)) = 0 на всей прямой x = y, там же f = 0. Гессиан [[2, −2], [−2, 2]] имеет собственные значения 0 и 4, то есть только ⪰ 0. Каждая точка прямой — минимум, но нестрогий: вдоль прямой f не растёт.

Поиграй

Здесь функция с плоским дном. Поставь x* внутрь отрезка [−1, 1]: минимум локальный, но нестрогий. Переключи функцию на «x⁴»: в нуле минимум строгий, хотя f″(0) = 0.
