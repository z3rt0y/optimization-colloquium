Задача оптимизации (optimization problem: decision variable, objective, feasible set)

Задача оптимизации: найти min f(x) при условии x ∈ Ω, где

  • x ∈ ℝⁿ — переменная решения (decision variable): то, что мы выбираем;
  • f: ℝⁿ → ℝ — целевая функция (objective): то, что минимизируем;
  • Ω ⊆ ℝⁿ — допустимое множество (feasible set); точки x ∈ Ω называются допустимыми (feasible).

Обычно Ω = {x : gᵢ(x) ≤ 0, i = 1..m; hⱼ(x) = 0, j = 1..p}. При Ω = ℝⁿ задача безусловная (unconstrained). Решение x⋆ — минимизатор (minimizer), f⋆ = infx∈Ω f(x) — оптимальное значение (optimal value).

Интуиция

Любую задачу раскладываем на три вопроса: что я могу менять, как я оцениваю результат и что мне запрещено. Переменная решения — ручки, которые ты крутишь, целевая функция — табло со счётом, допустимое множество — правила игры. Максимизация сводится к минимизации: max f = −min(−f), поэтому в курсе всё записывают через min.

Подробнее

  • Оптимальное значение может не достигаться: у f(x) = eˣ на ℝ f⋆ = inf = 0, но точки минимума нет. Поэтому различают значение f⋆ (infimum) и минимизатор x⋆ (argmin).
  • Если Ω = ∅, задача недопустима (infeasible), принято f⋆ = +∞. Если f не ограничена снизу на Ω, задача неограничена (unbounded), f⋆ = −∞.
  • Ограничение-равенство иногда исключают подстановкой: задача становится безусловной и меньшей размерности (так решена задачка ниже).
  • Классы задач определяются видом f, gᵢ, hⱼ: линейное программирование (LP) — всё линейно; квадратичное (QP); выпуклое — f и gᵢ выпуклы, hⱼ аффинны. Для курса главный класс — выпуклый (№ 12, № 23).

В задачах и в коде

В Colab это первый шаг любой задачи: прежде чем звать оптимизатор, явно задаёшь x, f и Ω. Линейная регрессия: x = веса w ∈ ℝᵈ, f(w) = (1/2N)‖Xw − y‖², Ω = ℝᵈ. Портфель из задачки ниже: x — доли капитала в активах, f(x) = xᵀΣx — дисперсия доходности (риск), Ω — вероятностный симплекс {x ≥ 0, x₁ + … + xₙ = 1} (probability simplex, он есть в лекции 2).

import numpy as np
from scipy.optimize import minimize

sigma = np.array([[0.04, 0.01], [0.01, 0.09]])

def risk(x):
    return x @ sigma @ x

cons = [{"type": "eq", "fun": lambda x: x.sum() - 1}]
bounds = [(0, None), (0, None)]
res = minimize(risk, x0=np.array([0.5, 0.5]), bounds=bounds, constraints=cons)
print(res.x, res.fun)
# [0.7273 0.2727] 0.0318

Посчитай руками

Два актива с ковариационной матрицей Σ = [[0.04, 0.01], [0.01, 0.09]]. Найди доли x₁, x₂ ≥ 0, x₁ + x₂ = 1, при которых риск xᵀΣx минимален. Назови переменную решения, целевую функцию и допустимое множество.

Решение

Переменная решения x = (x₁, x₂). Целевая функция f(x) = 0.04x₁² + 2·0.01·x₁x₂ + 0.09x₂². Допустимое множество Ω = {x₁, x₂ ≥ 0, x₁ + x₂ = 1}.

Подставим x₁ = t, x₂ = 1 − t, t ∈ [0, 1]: f = 0.04t² + 0.02t(1 − t) + 0.09(1 − t)² = 0.11t² − 0.16t + 0.09.

f′(t) = 0.22t − 0.16 = 0 ⇒ t = 0.16/0.22 ≈ 0.727. Значит x⋆ ≈ (0.727, 0.273), f⋆ = 0.09 − 0.16²/(4·0.11) ≈ 0.0318, стандартное отклонение √0.0318 ≈ 17.8 %. Обе доли внутри [0, 1], так что ограничения x ≥ 0 не мешают.

Поиграй

Синяя точка — переменная решения x, цвет и линии уровня — значения целевой функции, треугольник — допустимое множество. Тащи x и смотри на значения ограничений. Оранжевый ромб — центр целевой функции, его тоже можно двигать.
