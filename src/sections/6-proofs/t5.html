Линейная сходимость градиентного спуска (linear convergence of GD)

Баулин filesColab: напрямуюЛекция 3, сл. 14–15 · Лекция 2, сл. 34–37
Формулировка · часть 2, 3 балла нажми, чтобы открыть

Пусть f µ-сильно выпукла и L-гладкая, шаг α = 1/L. Тогда

f(xₖ) − f⋆ ≤ (1 − µ/L)ᵏ (f(x₀) − f⋆).

Идея

Сильная выпуклость даёт условие PL: «градиент большой, если далеко от оптимума» (№ 16). Лемма о спуске говорит: «шаг уменьшает f пропорционально ‖∇f‖²». Вместе: каждый шаг съедает фиксированную долю µ/L оставшейся ошибки, получается геометрическая прогрессия.

Доказательство

  1. Шаг 1

    Сильная выпуклость даёт нижнюю модель. По определению (бонус теоремы 2) для любых y

    f(y) ≥ q(y) := f(x) + ⟨∇f(x), y − x⟩ + (µ/2)‖y − x‖².
  2. Шаг 2

    q — квадратичная функция от y. Из ∇q(y) = ∇f(x) + µ(y − x) = 0 находим y = x − ∇f(x)/µ и

    miny q(y) = f(x) − ‖∇f‖²/µ + ‖∇f‖²/(2µ) = f(x) − ‖∇f(x)‖²/(2µ).
  3. Шаг 3

    Берём y = x⋆: f⋆ = f(x⋆) ≥ q(x⋆) ≥ min q. Значит

    f⋆ ≥ f(x) − ‖∇f(x)‖²/(2µ)  ⇔  ‖∇f(x)‖² ≥ 2µ(f(x) − f⋆).

    Это условие Поляка–Лоясевича.

  4. Шаг 4

    Убывание за шаг. Из теоремы 4 при α = 1/L: f(xₖ₊₁) ≤ f(xₖ) − ‖∇f(xₖ)‖²/(2L).

  5. Шаг 5

    Комбинируем. Подставляем нижнюю оценку градиента. Член стоит со знаком минус, поэтому замена ‖∇f‖² на меньшую величину только увеличивает правую часть, и неравенство сохраняется:

    f(xₖ₊₁) ≤ f(xₖ) − (1/2L)·2µ(f(xₖ) − f⋆) = f(xₖ) − (µ/L)(f(xₖ) − f⋆).
  6. Шаг 6

    Вычитаем f⋆: f(xₖ₊₁) − f⋆ ≤ (1 − µ/L)(f(xₖ) − f⋆), и применяем это k раз. ■

Что спрашивают на коллоквиуме

  • Где использована сильная выпуклость? Только через PL (шаги 1–3). Поэтому теорема верна для любой L-гладкой функции с условием PL, даже невыпуклой (лекция 3, сл. 15; № 16).
  • Как множитель связан с κ? 1 − µ/L = 1 − 1/κ: чем больше число обусловленности (№ 15), тем ближе множитель к 1 и тем медленнее сходимость.
  • Почему множитель в [0, 1)? Всегда µ ≤ L, так как µI ⪯ ∇²f ⪯ LI.
  • Оценка точная? Для квадратичной функции ошибка по f падает быстрее, примерно как (1 − µ/L)² за шаг (в таблице кода ниже 0.5625 = 0.75²). Теорема даёт гарантию, а не точную скорость.

В коде

import numpy as np

q = np.diag([1.0, 4.0])
mu = 1.0
lip = 4.0
x = np.array([2.0, 1.0])
gap = 0.5 * x @ q @ x
for i in range(5):
    x = x - (q @ x) / lip
    new_gap = 0.5 * x @ q @ x
    print(i + 1, new_gap, new_gap / gap, "<=", 1 - mu / lip)
    gap = new_gap
# 1 1.125 0.28125 <= 0.75 # 2 0.6328 0.5625 <= 0.75 ← дальше каждый шаг 0.5625 = 0.75²

Проверь на числах

f = ½(x² + 4y²): µ = 1, L = 4, α = 1/4, x₀ = (2, 1). Проверь по шагам доказательства: PL в x₀, убывание из шага 4, итоговую оценку для f(x₁).

Решение

f₀ = ½(4 + 4) = 4, f⋆ = 0, ∇f(x₀) = (2, 4), ‖∇f‖² = 20.

PL: 20 ≥ 2µ(f₀ − f⋆) = 8 ✓.

x₁ = (2 − 0.5, 1 − 1) = (1.5, 0), f₁ = 1.125. Шаг 4: f₁ ≤ 4 − 20/8 = 1.5 ✓.

Итог: f₁ − f⋆ ≤ (1 − 1/4)·4 = 3 ✓, оценка выполнена с запасом.

Поиграй

GD с α = 1/L. Тащи старт на карте, меняй µ и L. Таблица проверяет каждое звено доказательства на каждой итерации: PL (шаг 3), убывание (шаг 4), итоговый множитель (шаг 6). Справа ошибка в логарифмической шкале против гарантии. Вторая функция неквадратичная: там µ = 1, L ≈ 5.30.
