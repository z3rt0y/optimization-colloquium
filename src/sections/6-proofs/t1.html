Критерий выпуклости первого порядка (first-order convexity criterion)

Баулин filesColab: для проверкиЛекция 2, сл. 11–15 · proofs.pdf §1
Формулировка · часть 2, 3 балла нажми, чтобы открыть

Пусть f дифференцируема на открытом выпуклом множестве C. Тогда

f выпукла  ⇔  f(y) ≥ f(x) + ⟨∇f(x), y − x⟩  для всех x, y ∈ C.

Идея

Касательная плоскость в любой точке лежит не выше графика: выпуклая функция всюду выше своих линейных приближений (№ 5). Для оптимизации это значит, что одна точка и градиент в ней дают нижнюю оценку f сразу на всём C. Если ∇f(x⋆) = 0, то f(y) ≥ f(x⋆) для всех y: стационарная точка выпуклой функции — глобальный минимум.

Доказательство

  1. (⇒) Из определения выпуклости следует неравенство
  2. Шаг 1

    Возьмём точку на отрезке zt = x + t(y − x) = (1 − t)x + ty, t ∈ (0, 1]. По определению выпуклости (№ 12)

    f(zt) ≤ (1 − t)f(x) + t f(y).
  3. Шаг 2

    Вычтем f(x) из обеих частей: f(zt) − f(x) ≤ t(f(y) − f(x)). Разделим на t > 0, знак сохраняется:

    [f(x + t(y − x)) − f(x)] / t ≤ f(y) − f(x).
  4. Шаг 3

    Слева разностное отношение вдоль направления d = y − x. При t ↓ 0 оно стремится к производной по направлению (№ 6), которая для дифференцируемой функции равна ⟨∇f(x), y − x⟩. Правая часть от t не зависит, нестрогое неравенство в пределе сохраняется:

    ⟨∇f(x), y − x⟩ ≤ f(y) − f(x).
  5. (⇐) Из неравенства следует выпуклость
  6. Шаг 4

    Фиксируем x, y, t ∈ [0, 1] и положим z = (1 − t)x + ty. Запишем неравенство дважды, оба раза с касательной в точке z:

    f(x) ≥ f(z) + ⟨∇f(z), x − z⟩,    f(y) ≥ f(z) + ⟨∇f(z), y − z⟩.
  7. Шаг 5

    Умножим первое на (1 − t) ≥ 0, второе на t ≥ 0 и сложим:

    (1 − t)f(x) + t f(y) ≥ f(z) + ⟨∇f(z), (1 − t)(x − z) + t(y − z)⟩.
  8. Шаг 6

    Ключевой момент: вектор в скалярном произведении равен нулю,

    (1 − t)(x − z) + t(y − z) = (1 − t)x + ty − z = 0.

    Остаётся (1 − t)f(x) + t f(y) ≥ f(z), а это определение выпуклости. ■

Что спрашивают на коллоквиуме

  • Почему касательную берут именно в z? Тогда при сложении линейные члены взаимно уничтожаются (шаг 6). С касательной в x или в y так не получится.
  • Зачем множители неотрицательны? Неравенства можно складывать с весами 1 − t, t ≥ 0; отрицательный множитель перевернул бы знак.
  • Где нужна выпуклость C? Точки zt и z должны лежать в C, иначе f(z) не определено. Открытость C нужна, чтобы градиент существовал в каждой точке, включая z.
  • Типичная ошибка: в шаге 3 написать строгое неравенство. В пределе строгое неравенство становится нестрогим.

Опирается на и нужно для

Опирается на определения № 12 (выпуклая функция) и № 6 (производная по направлению). Используется в теореме 2 (в обе стороны) и в шаге 2 теоремы 7.

Проверь на числах

f = eˣ, x = 0, y = 1. (а) Проверь неравенство критерия. (б) Посчитай разностное отношение шага 2 при t = 1, 0.5, 0.1 и убедись, что оно лежит между f′(x)(y − x) и f(y) − f(x). (в) Для (⇐) возьми t = 0.4 и проверь, что (1 − t)T(x) + tT(y) = f(z), где T — касательная в z. (г) Почему sin x на [0, π] не выпукла?

Решение

(а) f(1) = e ≈ 2.718 ≥ f(0) + f′(0)·1 = 2 ✓.

(б) Q(t) = (eᵗ − 1)/t: Q(1) ≈ 1.718, Q(0.5) ≈ 1.297, Q(0.1) ≈ 1.052. Все между f′(0)·1 = 1 и f(1) − f(0) ≈ 1.718, и при t → 0 стремятся к 1.

(в) z = 0.4, f(z) = e⁰·⁴ ≈ 1.4918. T(x) = e⁰·⁴(1 − 0.4) ≈ 0.8951, T(y) = e⁰·⁴(1 + 0.6) ≈ 2.3869. 0.6·0.8951 + 0.4·2.3869 ≈ 1.4918 = f(z) ✓: касательная линейна, поэтому взвешенная сумма её значений равна значению в z. Хорда: 0.6·1 + 0.4·e ≈ 1.6873 ≥ 1.4918 ✓.

(г) x = 0, y = π: f(π) = 0, а f(0) + cos 0·π = π. Неравенство 0 ≥ π ложно ⇒ не выпукла.

Поиграй

Режим (⇒): тащи точки x и y, двигай t или запусти «t → 0». Зелёная секущая наклоном даёт разностное отношение Q(t); нижний график показывает, как Q(t) спускается к ⟨∇f(x), y − x⟩. Режим (⇐): касательная в z и два неравенства шага 4. Выбери невыпуклую функцию, чтобы увидеть, где ломается цепочка.
