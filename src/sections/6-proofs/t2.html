Критерий выпуклости второго порядка (second-order convexity criterion)

Баулин filesColab: напрямуюЛекция 2, сл. 16–20 · Renegar Prop. 1.4.1, 1.4.2, 1.5.2
Формулировка · часть 2, 3 балла нажми, чтобы открыть
f ∈ C² на открытом выпуклом C выпукла  ⇔  ∇²f(x) ⪰ 0 для всех x ∈ C.

Идея

Многомерный случай сводим к одномерному. Функция выпукла тогда и только тогда, когда она выпукла вдоль каждой прямой, а для функции одной переменной выпуклость — это φ″ ≥ 0. Вдоль прямой x + td вторая производная равна dᵀ∇²f d, поэтому «выпукла вдоль всех прямых» и есть «∇²f ⪰ 0» (№ 10). Наглядно: гессиан ⪰ 0 значит, что нигде ни в одном направлении график не изогнут вниз.

Доказательство

  1. (⇒)
  2. Шаг 1

    Фиксируем x ∈ C и направление d. Положим φ(t) = f(x + td). Так как C открыто, φ определена при малых t любого знака. φ выпукла: сужение выпуклой функции на прямую выпукло (точки прямой с параметрами t₁, t₂ переходят в точки отрезка, и неравенство выпуклости для f сразу даёт его для φ).

  3. Шаг 2

    φ′ не убывает. По теореме 1 для φ в двух точках s и t:

    φ(s) ≥ φ(t) + φ′(t)(s − t),    φ(t) ≥ φ(s) + φ′(s)(t − s).

    При сложении φ(s) + φ(t) сокращается: 0 ≥ −(φ′(s) − φ′(t))(s − t), то есть (φ′(s) − φ′(t))(s − t) ≥ 0. При s > t получаем φ′(s) ≥ φ′(t).

  4. Шаг 3

    φ″(0) ≥ 0: производная неубывающей функции неотрицательна,

    φ″(0) = lims→0 (φ′(s) − φ′(0)) / s ≥ 0,

    так как числитель и знаменатель одного знака.

  5. Шаг 4

    Цепное правило (Renegar, Prop. 1.4.2): φ′(t) = ∇f(x + td)ᵀd, φ″(t) = dᵀ∇²f(x + td)d. Значит dᵀ∇²f(x)d = φ″(0) ≥ 0 для любого d, то есть ∇²f(x) ⪰ 0.

  6. (⇐)
  7. Шаг 5

    Пусть d = y − x. Формула Тейлора с остаточным членом в интегральной форме:

    f(y) = f(x) + ∇f(x)ᵀd + ∫₀¹ (1 − t) dᵀ∇²f(x + td) d dt.

    Это формула φ(1) = φ(0) + φ′(0) + ∫₀¹(1 − t)φ″(t)dt (интегрирование по частям) с подставленными φ′, φ″.

  8. Шаг 6

    Под интегралом (1 − t) ≥ 0 и dᵀ∇²f d ≥ 0, поэтому интеграл неотрицателен и

    f(y) ≥ f(x) + ∇f(x)ᵀ(y − x).

    По теореме 1 функция f выпукла. ■

Бонус: сильная выпуклость. Если ∇²f ⪰ µI, то dᵀ∇²f d ≥ µ‖d‖² и ∫₀¹(1 − t)µ‖d‖²dt = (µ/2)‖d‖². Получаем f(y) ≥ f(x) + ⟨∇f(x), d⟩ + (µ/2)‖d‖², то есть µ-сильную выпуклость (№ 13). Эта нижняя модель — шаг 1 теоремы 5.

Что спрашивают на коллоквиуме

  • Откуда (1 − t) в формуле Тейлора? Интегрирование по частям: ∫₀¹(1 − t)φ″(t)dt = [(1 − t)φ′(t)]₀¹ + ∫₀¹φ′(t)dt = −φ′(0) + φ(1) − φ(0). Отсюда φ(1) = φ(0) + φ′(0) + ∫₀¹(1 − t)φ″(t)dt.
  • Зачем C открыто? Чтобы φ была определена по обе стороны от нуля и предел в шаге 3 брался с обеих сторон.
  • А строгая выпуклость? ∇²f ≻ 0 всюду ⇒ f строго выпукла (Renegar, Prop. 1.4.1), обратное неверно: у x⁴ в нуле f″ = 0 (№ 13).
  • Где нужна f ∈ C²? В шаге 4 (существует φ″) и в шаге 5 (формула Тейлора с интегральным остатком).

В коде

Самый практичный критерий выпуклости: посчитать гессиан и проверить знаки собственных значений. На сетке это опровергает выпуклость, но не доказывает её (между узлами может быть что угодно); для квадратичных функций гессиан постоянен, и проверки в одной точке достаточно.

import numpy as np

def hess(x, y):
    return np.array([[1.0, 0.0], [0.0, -2 + 3 * y**2]])

worst = np.inf
for x in np.linspace(-2, 2, 41):
    for y in np.linspace(-2, 2, 41):
        worst = min(worst, np.linalg.eigvalsh(hess(x, y)).min())
print(worst)
# -2.0 ← для ½x² − y² + ¼y⁴ есть λ < 0: функция невыпукла

Проверь на числах

(а) Выпукла ли f = x² + xy + y²? (б) Для f = ½x² − y² + ¼y⁴ возьми x = (0, 0), d = (0, 1) и найди φ″(0). (в) Проверь формулу шага 5 для (б) при переходе от t = 0 к t = 1.

Решение

(а) ∇²f = [[2, 1], [1, 2]], собственные значения 1 и 3 ⇒ ∇²f ⪰ 0 всюду ⇒ выпукла (и даже 1-сильно выпукла).

(б) φ(t) = −t² + t⁴/4, φ″(t) = −2 + 3t², φ″(0) = −2 < 0 ⇒ вдоль этой прямой функция изогнута вниз ⇒ f невыпукла.

(в) φ(1) = −1 + 0.25 = −0.75. Правая часть: φ(0) + φ′(0) = 0, ∫₀¹(1 − t)(−2 + 3t²)dt = −2·½ + 3(⅓ − ¼) = −1 + 0.25 = −0.75 ✓.

Поиграй

Слева карта: тащи точку x и конец стрелки d. В центре — сужение φ(t) = f(x + td) и его квадратичная модель. Справа — φ″(0) = dᵀ∇²f(x)d для всех направлений: если кривая где-то уходит ниже нуля, функция невыпукла. В таблице проверка формулы Тейлора из шага 5.
