Достаточность условий ККТ в выпуклом случае (sufficiency of the KKT conditions)

Баулин filesColab: для проверкиЛекция 2, вторая часть · B&V §5.5.3 · proofs.pdf §7
Формулировка · часть 2, 3 балла нажми, чтобы открыть

Пусть f, gᵢ выпуклы, hⱼ аффинны, и (x⋆, λ⋆, ν⋆) удовлетворяет условиям ККТ. Тогда x⋆ — глобальный минимум задачи min f(x) при gᵢ(x) ≤ 0, hⱼ(x) = 0.

Условия ККТ (№ 23): стационарность ∇ₓℒ(x⋆, λ⋆, ν⋆) = 0; допустимость gᵢ(x⋆) ≤ 0, hⱼ(x⋆) = 0; λᵢ⋆ ≥ 0; дополняющая нежёсткость λᵢ⋆gᵢ(x⋆) = 0.

Идея

Цепочка из трёх звеньев для любого допустимого x: f(x) ≥ ℒ(x) ≥ ℒ(x⋆) = f(x⋆), где ℒ(x) := ℒ(x, λ⋆, ν⋆) (№ 22). Первое звено даёт знак λ, второе — выпуклость и стационарность, третье — дополняющая нежёсткость.

Доказательство

  1. Шаг 1

    Лагранжиан выпуклый по x: ℒ(x, λ⋆, ν⋆) = f(x) + Σᵢλᵢ⋆gᵢ(x) + Σⱼνⱼ⋆hⱼ(x).

    • f выпукла;
    • λᵢ⋆gᵢ выпуклы, потому что λᵢ⋆ ≥ 0 (с отрицательным коэффициентом выпуклая функция стала бы вогнутой);
    • νⱼ⋆hⱼ аффинны при любом знаке ν: поэтому на ν нет ограничения знака, и поэтому равенства должны быть аффинными.

    Сумма выпуклых функций выпукла (бонус в конце раздела).

  2. Шаг 2

    ℒ минимален в x⋆. По теореме 1 и стационарности для всех x:

    ℒ(x) ≥ ℒ(x⋆) + ∇ₓℒ(x⋆)ᵀ(x − x⋆) = ℒ(x⋆),   так как ∇ₓℒ(x⋆) = 0.
  3. Шаг 3

    ℒ ≤ f на допустимом множестве. Если x допустим, то λᵢ⋆ ≥ 0, gᵢ(x) ≤ 0 ⇒ λᵢ⋆gᵢ(x) ≤ 0, а hⱼ(x) = 0. Значит ℒ(x) ≤ f(x).

  4. Шаг 4

    В x⋆ равенство. По дополняющей нежёсткости λᵢ⋆gᵢ(x⋆) = 0, по допустимости hⱼ(x⋆) = 0, поэтому ℒ(x⋆) = f(x⋆).

  5. Итог

    Для любого допустимого x:

    f(x) ≥ш.3 ℒ(x) ≥ш.2 ℒ(x⋆) =ш.4 f(x⋆).  ■

Что спрашивают на коллоквиуме

Где использовано каждое условие (любимый вопрос):

  • стационарность → шаг 2;
  • λ ≥ 0 → шаги 1 и 3;
  • допустимость x⋆ → x⋆ вообще кандидат, плюс шаг 4;
  • дополняющая нежёсткость → шаг 4;
  • выпуклость f, gᵢ и аффинность hⱼ → шаг 1.

Без выпуклости условия ККТ лишь необходимы (при условиях регулярности, № 23), но не достаточны. В виджете пример: у x³ − 3x на [−2.2, 2] условиям ККТ удовлетворяют три точки, и одна из них — локальный максимум.

В коде

import numpy as np

def f(v):
    return (v[0] - 3)**2 + (v[1] - 2)**2

def lagr(v):
    return f(v) + 2.0 * (v[0] + v[1] - 3)

rng = np.random.default_rng(0)
ok = True
for i in range(10000):
    v = rng.uniform(0, 3, size=2)
    if v.sum() > 3:
        continue
    ok = ok and f(v) >= lagr(v) >= lagr(np.array([2.0, 1.0])) - 1e-12
print(ok, lagr(np.array([2.0, 1.0])))
# True 2.0 ← цепочка f ≥ ℒ ≥ ℒ(x⋆) = 2 верна во всех допустимых точках задачи P

Проверь на числах

Задача P (№ 21–24): min (x₁ − 3)² + (x₂ − 2)² при x₁ + x₂ ≤ 3, x ≥ 0; x⋆ = (2, 1), λ⋆ = (2, 0, 0). Пройди цепочку для допустимых x = (0, 0) и x = (1, 1).

Решение

ℒ(x) = f(x) + 2(x₁ + x₂ − 3) (множители при −x₁, −x₂ нулевые).

x = (0, 0): f = 9 + 4 = 13, ℒ = 13 + 2·(−3) = 7, ℒ(x⋆) = f(x⋆) = 1 + 1 = 2. Цепочка 13 ≥ 7 ≥ 2 = 2 ✓.

x = (1, 1): f = 4 + 1 = 5, ℒ = 5 − 2 = 3: 5 ≥ 3 ≥ 2 ✓.

Поиграй

Серая кривая — f, синяя — ℒ(·, λ), зелёная зона — допустимое множество. Тащи пробную точку x: справа цепочка f(x) ≥ ℒ(x) ≥ ℒ(x⋆) = f(x⋆) с проверкой каждого звена. В выпуклой задаче попробуй λ ≠ λ⋆ и λ < 0. В невыпуклой выбери кандидата среди точек ККТ и посмотри, какое звено ломается.
