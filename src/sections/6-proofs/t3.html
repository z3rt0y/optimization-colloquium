Достаточное условие минимума второго порядка (second-order sufficient condition)

Формулировка · часть 2, 3 балла нажми, чтобы открыть

Если f ∈ C², ∇f(x⋆) = 0 и ∇²f(x⋆) ≻ 0, то x⋆ — строгий локальный минимум.

Идея

В стационарной точке линейный член формулы Тейлора равен нулю, поведение задаёт квадратичная форма ½hᵀ∇²f h. Она положительна в x⋆, а по непрерывности остаётся положительной и рядом. Вся тонкость в слове «рядом»: остаток Тейлора вычисляется не в x⋆, а в промежуточной точке ξ.

Доказательство

  1. Шаг 1

    Число m. Пусть m = λmin(∇²f(x⋆)) > 0. Для симметричной матрицы hᵀAh ≥ λmin(A)‖h‖² (в собственном базисе hᵀAh = Σλᵢcᵢ² ≥ λmin Σcᵢ²), поэтому hᵀ∇²f(x⋆)h ≥ m‖h‖².

  2. Шаг 2

    Переносим оценку в окрестность. Гессиан непрерывен, а λmin непрерывно зависит от элементов матрицы. Поэтому найдётся r > 0 такое, что при ‖x − x⋆‖ < r

    hᵀ∇²f(x)h ≥ (m/2)‖h‖²  для всех h.

    Можно взять любое число строго меньше m, половина для удобства.

  3. Шаг 3

    Тейлор с остатком в форме Лагранжа. Для 0 < ‖h‖ < r найдётся ξ на отрезке [x⋆, x⋆ + h]:

    f(x⋆ + h) = f(x⋆) + ∇f(x⋆)ᵀh + ½hᵀ∇²f(ξ)h,   где ∇f(x⋆)ᵀh = 0.

    Это одномерная формула Лагранжа для φ(t) = f(x⋆ + th) на [0, 1].

  4. Шаг 4

    ξ лежит на отрезке, поэтому ‖ξ − x⋆‖ ≤ ‖h‖ < r, и к ней применима оценка шага 2:

    f(x⋆ + h) − f(x⋆) ≥ ½ · (m/2)‖h‖² = (m/4)‖h‖² > 0.

    Строгое неравенство при всех h ≠ 0 из шара — это строгий локальный минимум (№ 3). ■

Что спрашивают на коллоквиуме

  • Почему нельзя сразу подставить ∇²f(x⋆)? Остаток вычисляется в неизвестной точке ξ, а не в x⋆, поэтому и нужен шаг 2.
  • Хватит ли ∇²f ⪰ 0? Нет: у f(x) = x³ в нуле f′ = f″ = 0, а минимума нет.
  • Это условие необходимое? Нет: у x⁴ строгий минимум в нуле, хотя f″(0) = 0.
  • Минимум глобальный? Только локальный: у x² + 2y² − x³ в нуле строгий локальный минимум, но f(1.5, 0) = −1.125 < 0.

Опирается на и нужно для

Определения № 3, № 8, № 10. Тот же приём «оценка λmin в окрестности» — шаг 3 теоремы 6.

В коде

Радиус r из шага 2 в коде проверяют перебором по окружностям: минимум разности f(x⋆ + h) − f(x⋆) − (m/4)‖h‖² по шару должен быть ≥ 0.

import numpy as np

m = 2.0
worst = np.inf
for r in np.linspace(0.001, 1 / 6, 50):
    for t in np.linspace(0, 2 * np.pi, 200):
        h = r * np.array([np.cos(t), np.sin(t)])
        gain = h[0]**2 + 2 * h[1]**2 - h[0]**3
        worst = min(worst, gain - m / 4 * r**2)
print(worst)
# 5.0e-07 ← оценка шага 4 выполнена во всём шаре r = 1/6

Проверь на числах

f(x, y) = x² + 2y² − x³. Проверь, что (0, 0) стационарна, найди m, радиус r из шага 2 (с порогом m/2) и проверь оценку шага 4 при h = (0.1, 0).

Решение

∇f = (2x − 3x², 4y) = (0, 0) в нуле ✓. ∇²f(x, y) = diag(2 − 6x, 4), в нуле diag(2, 4) ⇒ m = 2.

λmin(∇²f) = min(2 − 6x, 4) ≥ m/2 = 1 ⇔ x ≤ 1/6. Худшие точки шара лежат на оси x, поэтому r = 1/6.

h = (0.1, 0): f = 0.01 − 0.001 = 0.009 ≥ (m/4)‖h‖² = 0.5·0.01 = 0.005 ✓. Для сравнения, вне шара f(1.5, 0) = −1.125: теорема только локальная.

Поиграй

Слева карта: синий круг — шар радиуса r из шага 2, оранжевая линия — где λmin(∇²f) падает до m/2, пунктир — где гессиан перестаёт быть ≻ 0. Задай направление u: справа срез f(x⋆ + su) − f(x⋆) и нижняя оценка (m/4)s². Внутри шара оценка держится, вне его может нарушаться. Вариант y² + x³ показывает, что ⪰ 0 недостаточно.
