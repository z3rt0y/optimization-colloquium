Лемма о спуске и следствие для шага GD (descent lemma and its corollary)

Баулин filesColab: напрямуюЛекция 2, сл. 27–31 · Лекция 3, сл. 7–8 · Renegar Thm 1.5.1
Формулировка · часть 2, 3 балла нажми, чтобы открыть

Если ∇f является L-липшицевым, то

f(y) ≤ f(x) + ⟨∇f(x), y − x⟩ + (L/2)‖y − x‖².

Для шага GD x⁺ = x − α∇f(x):  f(x⁺) ≤ f(x) − α(1 − Lα/2)‖∇f(x)‖².

Идея

Функция лежит не выше параболы, касающейся её в x. Это верхняя оценка, «двойник» выпуклости, которая даёт нижнюю (теорема 1). Верхняя парабола — модель, которую GD честно минимизирует: её вершина — ровно шаг с α = 1/L.

Доказательство

  1. Лемма
  2. Шаг 1

    Пусть d = y − x, φ(t) = f(x + td). По формуле Ньютона–Лейбница (Renegar, Thm 1.5.1)

    f(y) − f(x) = ∫₀¹ φ′(t) dt = ∫₀¹ ∇f(x + td)ᵀd dt.
  3. Шаг 2

    Добавим и вычтем ∇f(x) под интегралом:

    f(y) − f(x) = ∇f(x)ᵀd + ∫₀¹ [∇f(x + td) − ∇f(x)]ᵀd dt.
  4. Шаг 3

    Оцениваем подынтегральное выражение: по Коши–Буняковскому […]ᵀd ≤ ‖∇f(x + td) − ∇f(x)‖·‖d‖; по липшицевости ‖∇f(x + td) − ∇f(x)‖ ≤ L‖td‖ = Lt‖d‖. Итого подынтегральное выражение не больше Lt‖d‖².

  5. Шаг 4

    ∫₀¹ Lt dt = L/2, откуда f(y) − f(x) ≤ ∇f(x)ᵀd + (L/2)‖d‖². Лемма доказана.

  6. Следствие
  7. Шаг 5

    Подставим y = x − α∇f(x), то есть d = −α∇f(x): ⟨∇f, d⟩ = −α‖∇f‖², ‖d‖² = α²‖∇f‖².

    f(x⁺) ≤ f(x) − α‖∇f(x)‖² + (Lα²/2)‖∇f(x)‖² = f(x) − α(1 − Lα/2)‖∇f(x)‖².  ■
Выводы. При 0 < α < 2/L скобка положительна, и f строго убывает, пока ∇f ≠ 0: отсюда безопасный шаг α < 2/L во всех задачах блока B. Множитель α(1 − Lα/2) максимален при α = 1/L (производная 1 − Lα = 0) и равен 1/(2L): f(x⁺) ≤ f(x) − ‖∇f(x)‖²/(2L). Эта формула нужна в теореме 5.

Что спрашивают на коллоквиуме

  • Где используется липшицевость? Только в шаге 3. Выпуклость в лемме не нужна.
  • Откуда L/2? Из ∫₀¹ t dt = ½: множитель t пришёл из ‖td‖ = t‖d‖ (t ≥ 0).
  • Почему при α = 2/L нет гарантии? Скобка 1 − Lα/2 = 0, оценка даёт только f(x⁺) ≤ f(x). На x² + y² с α = 1 = 2/L так и происходит: колебания без убывания (задача B3).

В коде

Лемму удобно проверять на случайных парах точек: разность «парабола минус функция» должна быть ≥ 0. Для ln cosh x имеем f″ = 1 − tanh² ≤ 1, то есть L = 1.

import numpy as np

def f(x):
    return np.log(np.cosh(x))

def df(x):
    return np.tanh(x)

rng = np.random.default_rng(0)
lip = 1.0
worst = np.inf
for i in range(100000):
    x = rng.uniform(-5, 5)
    y = rng.uniform(-5, 5)
    upper = f(x) + df(x) * (y - x) + lip / 2 * (y - x)**2
    worst = min(worst, upper - f(y))
print(worst)
# 4.8e-11 ← ни одной пары, где функция выше параболы

Проверь на числах

f = ln cosh x, L = 1, x = 1, y = 2. (а) Проверь лемму. (б) Посчитай остаток f(y) − f(x) − f′(x)d и сравни с (L/2)d². (в) Сделай шаг GD с α = 1/L и проверь следствие.

Решение

f(1) ≈ 0.4338, f(2) ≈ 1.3250, f′(1) = tanh 1 ≈ 0.7616, d = 1.

(а) 0.4338 + 0.7616 + 0.5 = 1.6954 ≥ 1.3250 ✓.

(б) Остаток 1.3250 − 0.4338 − 0.7616 ≈ 0.1296 ≤ 0.5 ✓; это и есть интеграл шага 2.

(в) x⁺ = 1 − 0.7616 = 0.2384, f(x⁺) ≈ 0.0282. Гарантия: f(1) − 0.7616²/2 ≈ 0.1438 ≥ 0.0282 ✓.

Поиграй

Слева подынтегральное выражение шага 2, g(t) = (f′(x + td) − f′(x))·d, и его оценка Ltd² из шага 3: площади под ними — остаток и (L/2)d². Справа следствие: реальное убывание за шаг GD, делённое на f′(x)², против гарантии α(1 − Lα/2). Уменьши L ниже настоящего — оценки начнут ломаться.
