Поиск шага по Армихо (Armijo backtracking)

Матвеева filesColab: напрямую№ 19
Условие

Для f(x) = x²: начальная точка x = 2, направление d = −4, параметр c = 1/4. Начни с α₀ = 1, уменьшай шаг вдвое и остановись на первом принятом значении. Сначала запиши условие принятия шага. Таблица: попытка, шаг, левая часть условия, правая часть, принять или отклонить. Почему недостаточно проверять только уменьшение функции?

Подсказка

Условие Армихо: f(x + αd) ≤ f(x) + c·α·f′(x)·d. Посчитай f′(2)·d один раз, правая часть станет линейной функцией α.

Решение
  1. Условие

    f(x + αd) ≤ f(x) + c·α·f′(x)·d. Здесь f(2) = 4, f′(2) = 4, f′(2)·d = −16 < 0 (d — направление спуска, это антиградиент). Правая часть: 4 + ¼·α·(−16) = 4 − 4α.

  2. Попытка 1

    α = 1: левая f(2 − 4) = f(−2) = 4, правая 4 − 4 = 0. 4 ≤ 0 — нет ⇒ отклонить.

  3. Попытка 2

    α = 1/2: левая f(0) = 0, правая 4 − 2 = 2. 0 ≤ 2 ⇒ принять. Третья попытка не нужна.

  4. Итог

    x⁺ = 2 + ½·(−4) = 0 — ровно минимум x².

  5. Почему мало «f уменьшилась»

    При α = 1 точка перепрыгнула минимум: из 2 в −2, выигрыш ноль. Простое условие f(x⁺) < f(x) пропускает такие перелёты, если выигрыш хоть чуть-чуть больше нуля. Пример для f = x²: xₖ = (−1)ᵏ(1 + 2⁻ᵏ). Значения f(xₖ) строго убывают к 1, но точки прыгают между окрестностями −1 и 1 и к минимуму 0 не идут. Каждый такой шаг почти равен α ≈ 1, а выигрыш около 2⁻ᵏ → 0. Армихо требует выигрыш не меньше c·α·|f′(x)d|: здесь это больше 1, и все эти шаги отклоняются (проверено кодом). Слишком мелкие шаги отсекает сам бэктрекинг: он начинает с α₀ и уменьшает шаг, только пока условие не выполнено.

Ответ: попытка 1 (α = 1): 4 против 0 — отклонить; попытка 2 (α = 1/2): 0 против 2 — принять; итоговая точка x = 0.

В коде

import numpy as np


def newton_step(grad, hess, x):
    d = np.linalg.solve(hess(x), -grad(x))
    return x + d


def armijo(f, df, x, d, c=0.25, alpha=1.0, beta=0.5):
    fx = f(x)
    slope = df(x) * d
    while f(x + alpha * d) > fx + c * alpha * slope:
        print("отклонить", alpha)
        alpha = beta * alpha
    print("принять", alpha)
    return alpha


def grad(p):
    return np.array([4 * (p[0] - 3), 2 * (p[1] + 2)])


def hess(p):
    return np.array([[4.0, 0.0], [0.0, 2.0]])


def f(t):
    return t * t


def df(t):
    return 2 * t


print(newton_step(grad, hess, np.array([5.0, 4.0])))
a = armijo(f, df, 2.0, -4.0)
print(2.0 + a * -4.0)
# [ 3. -2.] # отклонить 1.0 # принять 0.5 # 0.0

Поиграй

Чёрная кривая — f(x + αd) как функция шага, оранжевый пунктир — правая часть Армихо, серый — уровень f(x). Зелёная полоса на оси — шаги, которые принимаются. Запусти попытки по очереди, затем включи «только f уменьшилась» и сравни. Попробуй c ближе к 1 или d не по антиградиенту.
