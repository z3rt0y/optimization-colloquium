П1 · тетрадь, с. 4

Стационарная точка, тип, µ, L, κ и шаг (stationary point, type, step size)

Матвеева filesColab: напрямуютип задачи 3.1
Условие

f(x, y) = 2x² + 2xy + 2y² − 6x

Найди все стационарные точки и определи их тип. Объясни, является ли минимум глобальным и единственным. Найди µ, L, κ, интервал безопасных постоянных шагов и стандартный шаг.

Подсказка

Иди по строкам тетради: градиент → система → точка → гессиан → миноры или λ → тип → глобальность → f(x⋆) → µ, L, κ, шаг → проверка подстановкой. Для квадратичной функции гессиан постоянный.

Решение по строкам тетради
  1. Градиент

    ∇f = (4x + 2y − 6,  2x + 4y).

  2. Система

    4x + 2y = 6, 2x + 4y = 0.

  3. Точка

    Из второго x = −2y ⇒ −8y + 2y = 6 ⇒ y = −1, x = 2. x⋆ = (2, −1). Других нет: det H ≠ 0, у линейной системы одно решение.

  4. Гессиан

    H = [[4, 2], [2, 4]], одинаковый во всех точках.

  5. Миноры, λ

    Δ₁ = 4 > 0, Δ₂ = 16 − 4 = 12 > 0 ⇒ H ≻ 0 по критерию Сильвестра (Sylvester's criterion). Собственные значения: λ² − 8λ + 12 = 0 ⇒ λ = 2 (вектор (1, −1)) и λ = 6 (вектор (1, 1)).

  6. Тип

    ∇f(x⋆) = 0 и H ≻ 0 ⇒ строгий локальный минимум (теорема 3).

  7. Глобаль­ность

    H ⪰ 2I во всём ℝ² ⇒ f 2-сильно выпукла (№ 13) ⇒ локальный минимум глобальный, и он единственный: у строго выпуклой функции не больше одного минимизатора. Для квадратичной функции это видно и напрямую: f(x) = f(x⋆) + ½(x − x⋆)ᵀH(x − x⋆) точно, а квадратичная форма с H ≻ 0 больше нуля везде, кроме x = x⋆.

  8. f(x⋆)

    2·4 + 2·2·(−1) + 2·1 − 6·2 = 8 − 4 + 2 − 12 = −6.

  9. µ, L, κ, шаг

    µ = λmin = 2, L = λmax = 6, κ = L/µ = 3. Безопасные постоянные шаги: 0 < α < 2/L = 1/3; стандартный шаг α = 1/L = 1/6. Лучший постоянный шаг для квадратичной функции — 2/(L + µ) = 1/4.

  10. Проверка

    ∇f(2, −1) = (8 − 2 − 6,  4 − 4) = (0, 0) ✓. Ещё одна проверка: f(0, 0) = 0, а формула выше даёт −6 + ½(−2, 1)H(−2, 1)ᵀ = −6 + ½·12 = 0 ✓.

Ответ: единственная стационарная точка (2, −1), строгий глобальный минимум, f⋆ = −6; µ = 2, L = 6, κ = 3, шаги 0 < α < 1/3, стандартный α = 1/6.

Калькулятор: П1 и задачи 1 пробных билетов

Коэффициенты f = ax² + bxy + cy² + dx + ey. Калькулятор пишет решение по шагам, как в тетради, включая µ, L, κ и шаги. На карте: звезда — минимум, стрелки — собственные направления, пунктир — прямые ∂f/∂x = 0 и ∂f/∂y = 0 (их пересечение — x⋆). Синюю точку можно таскать.
