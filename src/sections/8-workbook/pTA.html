Часть 1 · шесть определений

    Часть 2 · теорема с доказательством

    Сформулируй и докажи лемму о спуске. Получи следствие для шага градиентного спуска и объясни интервал гарантированного строгого убывания.

    План ответа для самопроверки
    1. Условие: ∇f L-липшицев. Утверждение: f(y) ≤ f(x) + ⟨∇f(x), y − x⟩ + (L/2)‖y − x‖².
    2. Формула Ньютона–Лейбница вдоль отрезка: f(y) − f(x) = ∫₀¹ ⟨∇f(x + t(y − x)), y − x⟩ dt.
    3. Вычитаем ⟨∇f(x), y − x⟩, применяем Коши–Буняковского и липшицевость: подынтегральное выражение не больше Lt‖y − x‖², а ∫₀¹ Lt dt = L/2.
    4. Следствие: y = x − α∇f(x) ⇒ f(x⁺) ≤ f(x) − α(1 − Lα/2)‖∇f(x)‖².
    5. Интервал: при ∇f(x) ≠ 0 убывание строгое, если α(1 − Lα/2) > 0 ⇔ 0 < α < 2/L. Наибольшая гарантия при α = 1/L: f(x⁺) ≤ f(x) − ‖∇f‖²/(2L). При α = 2/L гарантия нулевая (пример — задача B3).

    Полное доказательство по шагам: теорема 4

    Задача 1

    f(x, y) = 3x² + 2xy + 3y² − 8x − 8y

    Найди стационарные точки и определи их тип с обоснованием. Уточни глобальность и единственность. Дополнительно: чему равны µ, L, κ и стандартный шаг?

    Решение задачи 1
    1. Градиент

      ∇f = (6x + 2y − 8,  2x + 6y − 8).

    2. Система

      6x + 2y = 8, 2x + 6y = 8. Вычитаем: 4x − 4y = 0 ⇒ x = y ⇒ 8x = 8 ⇒ x⋆ = (1, 1).

    3. Гессиан

      H = [[6, 2], [2, 6]]: Δ₁ = 6 > 0, det = 32 > 0 ⇒ H ≻ 0. λ = 4 (вектор (1, −1)) и 8 (вектор (1, 1)).

    4. Тип

      Строгий минимум; глобальный и единственный, потому что H ≻ 0 всюду и f сильно выпукла.

    5. Значение

      f(1, 1) = 3 + 2 + 3 − 8 − 8 = −8. Проверка: ∇f(1, 1) = (6 + 2 − 8, 2 + 6 − 8) = (0, 0) ✓.

    6. µ, L, κ

      µ = 4, L = 8, κ = 2; стандартный шаг 1/L = 1/8, безопасно 0 < α < 1/4.

    Задача 2

    f(x, y) = (x + 1)² + 3y²,   x₀ = (7, 4),   α = 1/4

    Выполни три шага, укажи градиенты и значения функции. Найди L и проверь шаг. Объясни поведение координат относительно минимума.

    Решение задачи 2
    1. Данные

      ∇f = (2(x + 1),  6y), H = diag(2, 6), x⋆ = (−1, 0). L = 6, 2/L = 1/3 > α = 1/4 ⇒ шаг безопасен.

    2. k = 0

      x₀ = (7, 4), ∇f = (16, 24), f = 64 + 48 = 112.

    3. k = 1

      x₁ = (7 − 4, 4 − 6) = (3, −2), ∇f = (8, −12), f = 16 + 12 = 28.

    4. k = 2

      x₂ = (3 − 2, −2 + 3) = (1, 1), ∇f = (4, 6), f = 4 + 3 = 7.

    5. k = 3

      x₃ = (1 − 1, 1 − 1.5) = (0, −0.5), f = 1 + 0.75 = 1.75.

    6. Поведение

      Множители: 1 − 2α = 1/2 по x, 1 − 6α = −1/2 по y. Ошибка x + 1: 8 → 4 → 2 → 1, монотонно. Координата y: 4 → −2 → 1 → −0.5 — колеблется вокруг 0 с затуханием. f уменьшается в 4 раза за шаг: 112 → 28 → 7 → 1.75. Здесь α = 2/(L + µ) = 1/4 — оптимальный постоянный шаг, оба множителя по модулю равны.
