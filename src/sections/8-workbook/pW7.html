Ограничения и двойственность (KKT conditions and the dual problem)

Матвеева filesColab: для проверки№ 21–24, теорема 7
Условие

min (x − 3)²  при  x ≤ 1

Приведи ограничение к виду g(x) ≤ 0. Запиши лагранжиан и все четыре группы ККТ. Проверь активный и неактивный случаи. Обоснуй глобальность найденного решения.

Двойственная задача. При фиксированном множителе минимизируй лагранжиан по всем вещественным x. Найди q(λ), реши двойственную задачу и сравни оптимальные значения.

Дополнительно. Замени ограничение на x ≤ 4. Как изменятся решение, активность и множитель? Может ли активное ограничение в другой задаче иметь нулевой множитель? Приведи пример.

Подсказка

Дополняющая нежёсткость λ·g(x) = 0 даёт ровно два случая: λ = 0 (неактивный) или g(x) = 0 (активный). Проверь в каждом остальные условия.

Решение по строкам тетради
  1. Ограничение, ℒ

    g(x) = x − 1 ≤ 0; ℒ(x, λ) = (x − 3)² + λ(x − 1).

  2. Группы ККТ
    Группа ККТУсловие для этой задачи
    Стационарность2(x − 3) + λ = 0
    Прямая допустимостьx − 1 ≤ 0
    Двойственная допустимостьλ ≥ 0
    Дополняющая нежёсткостьλ(x − 1) = 0
  3. Неактивный

    λ = 0 ⇒ x = 3, но 3 − 1 = 2 > 0: недопустимо ⇒ случай отпадает.

  4. Активный

    x = 1 ⇒ 2(1 − 3) + λ = 0 ⇒ λ = 4 ≥ 0 ✓. Точка ККТ: (x⋆, λ⋆) = (1, 4), f⋆ = 4.

  5. Глобаль­ность

    f выпукла (f″ = 2 > 0), g аффинна ⇒ задача выпуклая ⇒ точка ККТ — глобальный минимум (теорема 7). Проверка напрямую: на луче x ≤ 1 функция (x − 3)² убывает, минимум на правом конце.

  6. q(λ)

    При фиксированном λ ℒ — парабола по x: 2(x − 3) + λ = 0 ⇒ x(λ) = 3 − λ/2. Подставляем: q(λ) = (λ/2)² + λ(2 − λ/2) = 2λ − λ²/4.

  7. Двойственная

    max 2λ − λ²/4 при λ ≥ 0: q′ = 2 − λ/2 = 0 ⇒ λ⋆ = 4, d⋆ = 8 − 4 = 4 = p⋆. Зазор ноль — сильная двойственность (strong duality); условие Слейтера выполнено, например x = 0 строго допустима. И x(λ⋆) = 1 = x⋆.

  8. x ≤ 4

    g = x − 4. Неактивный случай: λ = 0 ⇒ x = 3 ≤ 4 ✓. Значит x⋆ = 3, ограничение неактивно, λ⋆ = 0, f⋆ = 0. Двойственная: q(λ) = −λ²/4 − λ, максимум при λ = 0, d⋆ = 0 = p⋆.

  9. Нулевой множитель

    Да. min (x − 1)² при x ≤ 1: x⋆ = 1, g(x⋆) = 0 — ограничение активно, но стационарность 2(1 − 1) + λ = 0 даёт λ⋆ = 0. Ограничение проходит ровно через безусловный минимум: если его убрать, решение не изменится. Дополняющая нежёсткость требует λg = 0, а не «ровно один из двух равен нулю».

Ответ: x⋆ = 1, λ⋆ = 4, f⋆ = 4, ограничение активно; q(λ) = 2λ − λ²/4, d⋆ = 4 = p⋆. При x ≤ 4: x⋆ = 3, λ⋆ = 0, ограничение неактивно.

Смысл λ⋆ = 4 — цена ограничения (sensitivity). Если ослабить его до x ≤ 1 + ε, оптимум станет (2 − ε)² = 4 − 4ε + ε², то есть уменьшится примерно на λ⋆·ε.

В коде

import numpy as np

x = np.linspace(-5, 1, 60001)
fx = (x - 3) ** 2
i = np.argmin(fx)
print("p* =", fx[i], "при x =", x[i])

lam = np.linspace(0, 8, 8001)
q = 2 * lam - lam ** 2 / 4
j = np.argmax(q)
print("d* =", q[j], "при λ =", lam[j])
# p* = 4.0 при x = 1.0 # d* = 4.0 при λ = 4.0

Поиграй

Слева f, лагранжиан и допустимая зона; синяя точка — минимум ℒ по всем x при текущем λ. Справа двойственная функция: при любом λ она не выше p⋆, а максимум касается p⋆. Двигай λ к λ⋆ и смотри, как минимум ℒ приходит в x⋆. Кнопки загружают задачу, дополнительный вопрос и пример с нулевым множителем.
