Часть 1 · шесть определений

Дай точные определения: глобальный минимум; градиент через линейное приближение; сильная выпуклость; число обусловленности; лагранжиан; двойственная функция и двойственная задача.

    Часть 2 · теорема с доказательством

    Сформулируй и докажи достаточность условий ККТ для глобального минимума выпуклой задачи. Назови роль каждого условия.

    План ответа для самопроверки
    1. Условия: f, gᵢ выпуклы, hⱼ аффинны, (x⋆, λ⋆, ν⋆) удовлетворяет ККТ. Обозначим ℒ(x) := ℒ(x, λ⋆, ν⋆).
    2. Двойственная допустимость λ⋆ ≥ 0 вместе с выпуклостью gᵢ и аффинностью hⱼ делает ℒ(x) выпуклой по x.
    3. Стационарность ∇ℒ(x⋆) = 0 плюс выпуклость ⇒ x⋆ — глобальный минимум ℒ (критерий 1-го порядка, теорема 1): ℒ(x) ≥ ℒ(x⋆).
    4. Для любого допустимого x: λᵢ⋆gᵢ(x) ≤ 0 (здесь снова нужна двойственная допустимость) и νⱼ⋆hⱼ(x) = 0 ⇒ f(x) ≥ ℒ(x).
    5. Дополняющая нежёсткость λᵢ⋆gᵢ(x⋆) = 0 и прямая допустимость hⱼ(x⋆) = 0 ⇒ ℒ(x⋆) = f(x⋆). Прямая допустимость ещё и гарантирует, что x⋆ — кандидат.
    6. Цепочка: f(x) ≥ ℒ(x) ≥ ℒ(x⋆) = f(x⋆) для любого допустимого x ⇒ x⋆ — глобальный минимум.

    Полное доказательство по шагам: теорема 7

    Задача 1

    f(x, y) = 2x² − 2xy + 2y² − 6x + 6y

    Найди стационарные точки и определи их тип с обоснованием. Уточни глобальность и единственность. Дополнительно: чему равны µ, L, κ и стандартный шаг?

    Решение задачи 1
    1. Градиент

      ∇f = (4x − 2y − 6,  −2x + 4y + 6).

    2. Система

      4x − 2y = 6, −2x + 4y = −6. Складываем: 2x + 2y = 0 ⇒ y = −x ⇒ 6x = 6 ⇒ x⋆ = (1, −1).

    3. Гессиан

      H = [[4, −2], [−2, 4]]: Δ₁ = 4 > 0, det = 12 > 0 ⇒ H ≻ 0. λ = 2 (вектор (1, 1)) и 6 (вектор (1, −1)).

    4. Тип

      Строгий минимум; глобальный и единственный (f сильно выпукла).

    5. Значение

      f(1, −1) = 2 + 2 + 2 − 6 − 6 = −6. Проверка: ∇f(1, −1) = (4 + 2 − 6, −2 − 4 + 6) = (0, 0) ✓.

    6. µ, L, κ

      µ = 2, L = 6, κ = 3; стандартный шаг 1/6, безопасно 0 < α < 1/3.

    Задача 2

    f(x, y) = x² + xy + y²,   x₀ = (6, 0),   α = 1/3

    Выполни три шага, укажи градиенты и значения функции. Найди L и проверь шаг. Объясни поведение через собственные направления.

    Решение задачи 2
    1. Данные

      ∇f = (2x + y,  x + 2y), H = [[2, 1], [1, 2]], λ = 1 (вектор (1, −1)) и 3 (вектор (1, 1)). L = 3, 2/L = 2/3 > α = 1/3 ⇒ шаг безопасен; это α = 1/L.

    2. k = 0

      x₀ = (6, 0), ∇f = (12, 6), f = 36; x₁ = (6 − 4, 0 − 2) = (2, −2).

    3. k = 1

      ∇f(2, −2) = (2, −2), f(x₁) = 4; x₂ = (4/3, −4/3).

    4. k = 2

      ∇f(x₂) = (4/3, −4/3), f(x₂) = 16/9 ≈ 1.7778; x₃ = (8/9, −8/9), f(x₃) = 64/81 ≈ 0.7901.

    5. Поведение

      x₀ = 3·(1, 1) + 3·(1, −1). Компонента вдоль (1, 1) (λ = 3) умножается на 1 − 3·(1/3) = 0 и исчезает за первый шаг: x₁ уже лежит на прямой y = −x. Компонента вдоль (1, −1) (λ = 1) умножается на 2/3: xₖ = 3·(2/3)ᵏ·(1, −1). После первого шага f убывает в 9/4 раза: f = 9·(4/9)ᵏ, то есть 4, 16/9, 64/81. Колебаний нет: оба множителя ≥ 0.
