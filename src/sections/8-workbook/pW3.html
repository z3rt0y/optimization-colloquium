Спуск со сдвинутым минимумом (GD with a shifted minimum)

Матвеева filesColab: напрямуютип задачи 3.2
Условие

f(x, y) = 2(x − 2)² + (y + 1)²,   x₀ = (6, 7),   α = 1/4

Выполни три шага градиентного спуска. Запиши градиент, гессиан, точку минимума, µ и L. Проверь выбранный шаг. До вычислений предположи, какая координата может попасть в оптимальное значение за один шаг. Затем объясни поведение: вокруг каких значений движутся координаты, какие множители у ошибок xₖ − x⋆ и yₖ − y⋆, есть ли колебания, почему значение функции уменьшается.

Подсказка

Гессиан диагональный, поэтому ошибки по координатам не связаны: eₖ₊₁ = (1 − αλ)·eₖ, где λ = 4 по x и λ = 2 по y.

Решение по строкам тетради
  1. Градиент

    ∇f = (4(x − 2),  2(y + 1)).

  2. Гессиан

    H = diag(4, 2), постоянный.

  3. Минимум, шаг

    x⋆ = (2, −1), f⋆ = 0; µ = 2, L = 4. Проверка шага: α = 1/4 < 2/L = 1/2 — строгое неравенство выполнено; более того, α = 1/L.

  4. Прогноз

    Множители 1 − 4α = 0 по x и 1 − 2α = 1/2 по y. Координата x попадёт в x⋆ = 2 за первый шаг, ошибка по y будет делиться пополам.

  5. k = 0

    x₀ = (6, 7), ∇f(x₀) = (16, 16), f(x₀) = 2·16 + 64 = 96.

  6. Первый переход

    x₁ = (6 − ¼·16,  7 − ¼·16) = (2, 3); ∇f(x₁) = (0, 8), f(x₁) = 16.

  7. Второй переход

    x₂ = (2, 3 − 2) = (2, 1); ∇f(x₂) = (0, 4), f(x₂) = 4.

  8. Третий переход

    x₃ = (2, 1 − 1) = (2, 0); f(x₃) = 1 (градиент в x₃ не требуется).

  9. Поведение

    Координаты движутся к x⋆ = (2, −1). Ошибка xₖ − 2: 4, 0, 0, 0 (множитель 0). Ошибка yₖ + 1: 8, 4, 2, 1 (множитель 1/2). Колебаний нет: оба множителя ≥ 0, знак ошибки не меняется. Значение f = 2(x − 2)² + (y + 1)² квадратично по ошибке, поэтому после первого шага оно падает в (1/2)² = 4 раза: 16 → 4 → 1.

Ответ: x₁ = (2, 3), x₂ = (2, 1), x₃ = (2, 0); f = 96, 16, 4, 1; µ = 2, L = 4, шаг безопасен.

Самопроверка из тетради:
  • вычислены три новые точки;
  • все компоненты каждого градиента взяты в одной старой точке;
  • значение функции посчитано отдельно от координат;
  • проверка шага содержит строгое неравенство α < 2/L.

В коде

Шаги GD для квадратичной функции со сдвинутым минимумом: ∇f(x) = H(x − x⋆), f(x) = ½(x − x⋆)ᵀH(x − x⋆).

import numpy as np


def gd_steps(h, x_star, x0, alpha, n):
    x = np.array(x0, dtype=float)
    for k in range(n + 1):
        e = x - x_star
        grad = h @ e
        f = 0.5 * e @ h @ e
        print(k, x, grad, f)
        x = x - alpha * grad


h = np.array([[4.0, 0.0], [0.0, 2.0]])
gd_steps(h, np.array([2.0, -1.0]), [6, 7], 0.25, 3)
# 0 [6. 7.] [16. 16.] 96.0 # 1 [2. 3.] [0. 8.] 16.0 # 2 [2. 1.] [0. 4.] 4.0 # 3 [2. 0.] [0. 2.] 1.0

Калькулятор шагов GD для тетради

Функция a(x − p)² + b(x − p)(y − q) + c(y − q)², минимум в (p, q). Кнопки загружают П3, П4, задачи 2 пробных билетов и два случая из П8. Таблица — готовое оформление для листа, включая ошибки xₖ − x⋆. Старт можно таскать по карте.
