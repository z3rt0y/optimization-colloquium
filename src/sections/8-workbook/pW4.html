Спуск со смешанным членом (GD with a cross term, eigen-directions)

Матвеева filesColab: напрямуютип задачи 3.2
Условие

f(x, y) = x² + xy + y²,   x₀ = (0, 6),   α = 1/2

Выполни три шага. Найди L, проверь шаг и объясни поведение через собственные направления гессиана. Почему здесь нельзя считать, что каждая обычная координата независимо умножается на 1 − αλ?

Подсказка

Запиши шаг как x⁺ = (I − αH)x и посмотри на матрицу I − ½H. Собственные векторы H здесь (1, 1) и (1, −1).

Решение
  1. Градиент, гессиан

    ∇f = (2x + y,  x + 2y), H = [[2, 1], [1, 2]].

  2. λ и векторы

    λ² − 4λ + 3 = 0 ⇒ λ = 1 (вектор (1, −1)) и λ = 3 (вектор (1, 1)). L = 3, 2/L = 2/3 > α = 1/2 ⇒ шаг безопасен.

  3. Матрица шага

    I − ½H = [[0, −½], [−½, 0]], то есть x⁺ = −y/2, y⁺ = −x/2. Новое x зависит от старого y — координаты связаны.

  4. k = 0

    ∇f(0, 6) = (6, 12), f = 36; x₁ = (0 − 3, 6 − 6) = (−3, 0).

  5. k = 1

    ∇f(−3, 0) = (−6, −3), f(x₁) = 9; x₂ = (−3 + 3, 0 + 1.5) = (0, 1.5).

  6. k = 2

    ∇f(0, 1.5) = (1.5, 3), f(x₂) = 2.25; x₃ = (−0.75, 0), f(x₃) = 0.5625.

  7. Собственный базис

    x₀ = 3·(1, 1) − 3·(1, −1). Компонента вдоль (1, 1) (λ = 3) за шаг умножается на 1 − 3/2 = −1/2: меняет знак и уменьшается вдвое. Компонента вдоль (1, −1) (λ = 1) умножается на 1 − 1/2 = 1/2. Проверка: x₁ = −1.5·(1, 1) − 1.5·(1, −1) = (−3, 0) ✓. Оба множителя по модулю 1/2, поэтому f падает ровно в 4 раза за шаг: 36 → 9 → 2.25 → 0.5625. Колебание вдоль (1, 1) видно в координатах: точки прыгают между осями.

  8. Почему не по координатам

    Формула 1 − αλ работает для координат в собственном базисе H. Здесь H недиагональна: член xy связывает x и y. Если подставить в эту формулу диагональный элемент H₁₁ = 2, получится 1 − ½·2 = 0 и «ответ» x₁ = (0, 0). Это неверно, на самом деле x₁ = (−3, 0).

Ответ: x₁ = (−3, 0), x₂ = (0, 1.5), x₃ = (−0.75, 0); f = 36, 9, 2.25, 0.5625; L = 3, шаг безопасен; множители −1/2 вдоль (1, 1) и 1/2 вдоль (1, −1).
