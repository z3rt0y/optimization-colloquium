Сначала предскажи поведение (error multipliers 1 − αλ)

Матвеева filesColab: напрямую№ 18, теорема 4
Условие

Для f(x, y) = x² + 3y² сравни четыре шага α = 1/6, 1/4, 1/3, 2/5. Найди множители ошибок и укажи, гарантирована ли сходимость из любой начальной точки. Что изменится в двух последних строках, если y₀ = 0?

Подсказка

H = diag(2, 6), поэтому xₖ₊₁ = (1 − 2α)xₖ, yₖ₊₁ = (1 − 6α)yₖ. Сходимость из любой точки ⇔ оба множителя по модулю меньше 1.

Решение

λ = 2 и 6, L = 6, 2/L = 1/3.

αпо x: 1 − 2αпо y: 1 − 6αповедениеиз любой точки
1/62/30y попадает в 0 за один шаг, x монотонно убывает ×2/3да
1/41/2−1/2x монотонно, y колеблется вокруг 0 и затухает; это 2/(L + µ), оба множителя по модулю равны — оптимальный постоянный шагда
1/31/3−1y колеблется без затухания: y, −y, y, … (граница α = 2/L)нет
2/51/5−7/5y колеблется и растёт в 1.4 раза за шаг — расходимостьнет

Если y₀ = 0. Тогда yₖ = (1 − 6α)ᵏ·0 = 0 на каждом шаге, и всё решает множитель по x: 1/3 и 1/5. В обеих последних строках метод сойдётся к (0, 0). Но это частный старт, а не гарантия: при α = 2/5 любая малая погрешность по y (хотя бы округление) будет расти в 1.4 раза за шаг. Сходимость «из любой точки» по-прежнему есть только при α < 2/L.

Поиграй

Слева оба множителя как функции шага: пока линия внутри зелёной полосы |·| < 1, ошибка по этой координате сжимается. Справа ошибки первых восьми шагов со старта (1, 1). Нажимай шаги из задачи, двигай ползунок, поставь галочку «y₀ = 0» и сравни последние строки таблицы.
