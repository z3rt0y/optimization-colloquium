Найди и исправь ошибку (spot the mistake)

Матвеева filesColab: для проверкисамопроверка
Условие

В каждой записи укажи ошибку и напиши корректный вариант. Где возможно, приведи контрпример. В конце ответь себе: какая из этих ошибок была ближе всего к твоей?

1. Производная смешанного члена. «У f = 3x² + 4xy + 2y² градиент равен (6x + 4x, 4x + 4y)».

Разбор

Ошибка: производная члена 4xy по x равна 4y, а не 4x. Верно: ∇f = (6x + 4y,  4x + 4y), H = [[6, 4], [4, 4]]. Проверка: в точке (0, 1) неверная формула даёт (0, 4), верная — (4, 4); разностное отношение (f(h, 1) − f(0, 1))/h = 3h + 4 → 4.

2. Тип стационарной точки. «Определитель гессиана положителен, поэтому точка — минимум».

Разбор

Ошибка: для 2×2 det H > 0 значит только, что оба λ одного знака: оба положительны или оба отрицательны. Верно: нужны ещё H₁₁ > 0 (критерий Сильвестра) и, конечно, ∇f = 0. Контрпример: f = −x² − y²: H = −2I, det = 4 > 0, а в нуле максимум. В размерности 3 знак det ещё слабее: diag(−1, −1, 1) имеет det = 1 > 0 и знаконеопределена.

3. Обновление координат. «Для f = x² − xy + y² из (2, 0) с шагом 1/2 сначала получаем новое x = 0, затем с ним считаем градиент по y и получаем новую точку (0, 0)».

Разбор

Ошибка: в GD все компоненты градиента берутся в одной старой точке. Так, как в записи, работает покоординатный спуск (Гаусса–Зейделя) — это другой метод. Верно: ∇f = (2x − y,  −x + 2y), ∇f(2, 0) = (4, −2) ⇒ x₁ = (2 − 2, 0 + 1) = (0, 1), f(x₁) = 1.

4. Множители ККТ. «Ограничение активно, значит его множитель строго положителен».

Разбор

Ошибка: активность g(x⋆) = 0 разрешает любое λ ≥ 0, включая 0: дополняющая нежёсткость требует только λg = 0. Верно обратное: если λ⋆ > 0, то ограничение активно. Контрпример: min (x − 1)² при x ≤ 1: активно, λ⋆ = 0 (см. П7).

5. Константа гладкости. «У f = −5x² + y² собственные значения гессиана равны −10 и 2. Значит, L = 2».

Разбор

Ошибка: L-гладкость — это ‖∇f(x) − ∇f(y)‖ ≤ L‖x − y‖. Для квадратичной f это ‖H(x − y)‖ ≤ L‖x − y‖, то есть L = max|λ| = 10, а не наибольшее λ. Контрпример к L = 2: x = (1, 0), y = 0: ‖∇f(x) − ∇f(y)‖ = ‖(−10, 0)‖ = 10 > 2·1. Заодно: f невыпукла (λ = −10 < 0), µ и κ не определены.

6. Убывание и сходимость. «Функция на каждом шаге уменьшается, поэтому точки обязательно сойдутся к глобальному минимуму».

Разбор

Ошибка: монотонное убывание f не гарантирует ни сходимости точек, ни глобальности. Контрпримеры:

  • f = x² − y² из (1, 0) с α = 1/4: f = 1, 0.25, 0.0625, … убывает, точки идут в (0, 0) — а это седло. Глобального минимума нет вообще: f не ограничена снизу.
  • f(x) = x⁴ − 4x² + x из x₀ = 1.5 с α = 0.02: f убывает, xₖ → 1.347 — локальный минимум (f ≈ −2.62), а глобальный в x ≈ −1.473 (f ≈ −5.44).
  • f = eˣ: f убывает к 0, точки уходят в −∞, минимизатора нет.

Верно: для выпуклой L-гладкой f с минимумом при 0 < α < 2/L значения сходятся к f⋆; для сильно выпуклой сходятся и точки, линейно (теорема 5).
