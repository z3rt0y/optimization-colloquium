Когда гессиан не решает вопрос (degenerate Hessian, higher-order terms)

Условие

Для каждой функции исследуй начало координат. Сначала проверь стационарность и гессиан, затем обоснуй фактический тип точки.

x⁴ + y⁴??
x⁴ − y⁴??

Почему одинаковый гессиан в точке может соответствовать разному поведению функции?

Подсказка

Формула Тейлора: f(h) = f(0) + ∇f(0)ᵀh + ½hᵀ∇²f(0)h + o(‖h‖²). Если квадратичный член в каком-то направлении равен нулю, знак f(h) − f(0) задают члены старших порядков. Тогда смотри на саму функцию.

Решение

У всех четырёх ∇f(0) = (0, 0): в каждой частной производной остаётся множитель x или y. Значит, начало координат стационарно везде, и вопрос только в типе.

ФункцияH(0)Тест 2-го порядкаТип и обоснование
x² − y²diag(2, −2)решает: λ разных знаковседло: f(t, 0) = t² > 0, f(0, t) = −t² < 0
−x² − y²diag(−2, −2)решает: H ≺ 0строгий максимум, причём глобальный: f ≤ 0 = f(0)
x⁴ + y⁴0не решаетстрогий глобальный минимум: f ≥ 0 = f(0), равенство только в 0
x⁴ − y⁴0не решаетседло: f(t, 0) = t⁴ > 0, f(0, t) = −t⁴ < 0 при любом малом t ≠ 0

Почему одинаковый гессиан даёт разное поведение. Гессиан описывает только квадратичную часть: f(h) − f(0) = ½hᵀHh + o(‖h‖²). Если H ≻ 0, то ½hᵀHh ≥ (λmin/2)‖h‖², и эта часть перебивает остаток — знак определён (теорема 3). Если у H есть нулевое собственное значение, вдоль соответствующего направления квадратичная часть равна нулю и знак задают члены 3-го, 4-го порядка. У x⁴ + y⁴ и x⁴ − y⁴ гессиан в нуле один и тот же (нулевой), а члены 4-го порядка разные — отсюда минимум в одном случае и седло в другом.

Что запомнить. Необходимое условие минимума: ∇f = 0 и H ⪰ 0 (necessary second-order condition). Достаточное: ∇f = 0 и H ≻ 0 (sufficient). Между ними, при вырожденном H ⪰ 0, тест молчит: может быть минимум (x² + y⁴) или седло (x² − y⁴) с одинаковым H = diag(2, 0).

Ловушка. Седло доказывают двумя направлениями: вдоль одного f выше f(0), вдоль другого ниже. А минимум проверкой по прямым не доказать. Функция f = (y − x²)(y − 3x²) имеет минимум в 0 вдоль каждой прямой через начало координат, но на параболе y = 2x² равна −x⁴ < 0, так что 0 — не минимум. Для минимума нужна оценка f(h) ≥ f(0) для всех малых h, как у x⁴ + y⁴ ≥ 0.

Поиграй

Слева карта знака f(h) − f(0) вокруг нуля. Справа срез вдоль направления u и квадратичная модель Тейлора. Когда H(0) = 0, модель — горизонтальная прямая и ничего не говорит, а срез показывает настоящий знак. Крути направление и сравнивай пары функций с одинаковым гессианом.
