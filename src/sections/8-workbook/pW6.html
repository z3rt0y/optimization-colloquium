Направление Ньютона (Newton direction)

Матвеева filesColab: напрямую№ 20, теорема 6
Условие

f(x, y) = 2(x − 3)² + (y + 2)²,   x₀ = (5, 4)

Найди градиент и гессиан, реши систему для направления Ньютона и выполни один полный шаг. Объясни результат через квадратичную модель.

Подсказка

Направление Ньютона — решение системы ∇²f(x₀)·d = −∇f(x₀); полный шаг — x₁ = x₀ + d (α = 1).

Решение
  1. Градиент

    ∇f = (4(x − 3),  2(y + 2)), ∇f(5, 4) = (8, 12).

  2. Гессиан

    ∇²f = diag(4, 2) в любой точке.

  3. Система

    4d₁ = −8, 2d₂ = −12 ⇒ d = (−2, −6). Это и есть d = −[∇²f]⁻¹∇f из определения № 20.

  4. Новая точка

    x₁ = (5 − 2, 4 − 6) = (3, −2), f(x₁) = 0, ∇f(x₁) = (0, 0). Это точный минимум.

  5. Почему так

    Ньютон минимизирует квадратичную модель m(d) = f(x₀) + ∇f(x₀)ᵀd + ½dᵀ∇²f(x₀)d. Для квадратичной f разложение Тейлора 2-го порядка точное, без остатка, то есть m(d) = f(x₀ + d). Минимум модели совпадает с минимумом f, поэтому хватает одного полного шага. Для сравнения GD с α = 1/L = 1/4: (5 − 2, 4 − 3) = (3, 1) — по x попал, по y нет, потому что кривизны разные. H⁻¹ делит каждое собственное направление на свою кривизну λ и выравнивает их.

Ответ: d = (−2, −6), x₁ = (3, −2) = x⋆, f(x₁) = 0.

Поиграй

Сплошные линии — уровни f, фиолетовый пунктир — те же уровни квадратичной модели в текущей точке. Для квадратичной функции пунктир ложится ровно на сплошные линии, и один шаг приводит в звезду. Выбери неквадратичную функцию: модель отличается от f, и шагов нужно несколько. Начальную точку можно таскать.
