Допустимое направление (feasible direction)

Colab: для проверкиЛекция 1, сл. 16–18
На коллоквиуме · 0.5 балла нажми, чтобы открыть

Вектор d ∈ ℝⁿ, d ≠ 0, — допустимое направление (feasible direction) в точке x ∈ Ω, если существует t₀ > 0 такое, что

x + t·d ∈ Ω для всех t ∈ [0, t₀].

Интуиция

Из x можно сделать хоть маленький шаг вдоль d и не вылететь из Ω. Во внутренней точке допустимы все направления, у ровной стенки — примерно половина (внутрь и вдоль стенки), в углу ещё меньше.

Подробнее

  • Многогранник Ω = {x : aᵢᵀx ≤ bᵢ}: d допустимо ⇔ aᵢᵀd ≤ 0 для всех активных ограничений (aᵢᵀx = bᵢ, № 21). Неактивные на малых t не мешают.
  • У кривой границы всё иначе: в круге касательное направление недопустимо, потому что x + td выходит из круга при любом t > 0. Допустимы только направления, строго смотрящие внутрь.
  • Необходимое условие 1-го порядка (лекция 1, сл. 17): если x* — локальный минимум f на Ω, то ∇f(x*)ᵀd ≥ 0 для всех допустимых d. Иначе говоря, из минимума нельзя спуститься, не нарушив ограничений. Во внутренней точке отсюда ∇f(x*) = 0.
  • Если Ω выпукло (№ 11), то y − x допустимо для любого y ∈ Ω, y ≠ x. Для выпуклой f условие ⟨∇f(x*), y − x*⟩ ≥ 0 ∀ y ∈ Ω становится критерием глобального минимума.

В задачах и в коде

Методы с простыми ограничениями (проекция на «ящик», L-BFGS-B из лекции 5, сл. 22) на каждом шаге определяют, какие переменные упёрлись в границу, и запрещают направления наружу. На ящике это одна проверка:

import numpy as np

lo = np.array([0.0, 0.0])
hi = np.array([1.0, 1.0])
x = np.array([1.0, 0.5])
d = np.array([-1.0, 1.0])
at_hi = np.isclose(x, hi)
at_lo = np.isclose(x, lo)
feasible = np.all(d[at_hi] <= 0) and np.all(d[at_lo] >= 0)
print(feasible)
# True

Посчитай руками

1) Ω = [0, 1]², x = (1, 0.5). Какие из d₁ = (−1, 1), d₂ = (1, 0), d₃ = (0, 1) допустимы? 2) Ω — единичный круг, x = (1, 0). Допустимы ли d = (0, 1) и d = (−1, 1)?

Решение

1) Активно ограничение x₁ ≤ 1, его нормаль a = (1, 0). d₁: aᵀd = −1 ≤ 0, допустимо; x + td = (1 − t, 0.5 + t) ∈ Ω при t ≤ 0.5, t₀ = 0.5. d₂: aᵀd = 1 > 0, недопустимо: (1 + t, 0.5) ∉ Ω ни при каком t > 0. d₃: aᵀd = 0, допустимо (движение вдоль стенки), t₀ = 0.5.

2) d = (0, 1): ‖(1, t)‖² = 1 + t² > 1 при любом t > 0 — недопустимо, хотя это касательная. d = (−1, 1): ‖(1 − t, t)‖² = 1 − 2t + 2t² ≤ 1 ⇔ t ≤ 1 — допустимо, t₀ = 1.

Поиграй

Тащи точку x (у границы она прилипает) и конец стрелки d. Кольцо вокруг точки показывает все направления: зелёные допустимы, красные нет. Сравни угол прямоугольника, ровную стенку и край круга.
