Производная по направлению (directional derivative)

На коллоквиуме · 0.5 балла нажми, чтобы открыть

Пусть d — допустимое направление в точке x ∈ Ω (№ 9). Производная f по направлению d (directional derivative):

∂f/∂d (x) = limt→0+ (f(x + td) − f(x)) / t.

Если f дифференцируема, то ∂f/∂d (x) = ⟨∇f(x), d⟩ = dᵀ∇f(x). При ‖d‖ = 1 это скорость роста f в направлении d.

Интуиция

Идёшь по поверхности строго в направлении d и меряешь крутизну подъёма под ногами. По градиенту подъём самый крутой, вдоль линии уровня крутизна нулевая, против градиента — самый крутой спуск.

Подробнее

  • Неравенство Коши–Буняковского (Cauchy–Schwarz) для ‖d‖ = 1: −‖∇f‖ ≤ ⟨∇f, d⟩ ≤ ‖∇f‖, максимум при d = ∇f/‖∇f‖ (лекция 3, сл. 4). Как функция угла θ между d и ∇f это ‖∇f‖·cos θ: правый график виджета.
  • Предел односторонний (t → 0+), поэтому производная по направлению бывает и у недифференцируемых функций: у f(x) = |x| в нуле ∂f/∂d = |d|. Формула ⟨∇f, d⟩ там неприменима: градиента нет.
  • d не обязан быть единичным: при замене d на cd (c > 0) производная умножается на c.
  • Вторая производная вдоль направления: d²/dt² f(x + td) |t=0 = dᵀ∇²f(x)d (Renegar, Prop. 1.4.2). На этом построено доказательство критерия выпуклости 2-го порядка.

В задачах и в коде

В линейном поиске (№ 19) изучают функцию одной переменной φ(α) = f(x + αd); её наклон в нуле φ′(0) = ∇f(x)ᵀd. Прямой режим автоматического дифференцирования (forward-mode AD, лекция 3, сл. 18) за один проход вычисляет произведение якобиана на вектор, то есть ровно производную по направлению.

import numpy as np

def f(x):
    return x[0]**2 * x[1] + x[1]**3

x = np.array([1.0, 2.0])
d = np.array([3.0, 4.0]) / 5
grad = np.array([2 * x[0] * x[1], x[0]**2 + 3 * x[1]**2])
print(grad @ d)
for t in [1e-1, 1e-3, 1e-5]:
    print(t, (f(x + t * d) - f(x)) / t)
# 12.8 # 0.1 13.36 0.001 12.8055 1e-05 12.80006 ← разность сходится к ⟨∇f, d⟩

Посчитай руками

f(x, y) = x²y + y³, точка (1, 2), направление d = (3, 4)/5. Найди ∂f/∂d и максимальную скорость роста f в этой точке.

Решение

∇f = (2xy, x² + 3y²) = (4, 13). ∂f/∂d = (4·3 + 13·4)/5 = 64/5 = 12.8.

Максимум по единичным направлениям равен ‖∇f‖ = √(16 + 169) = √185 ≈ 13.60 и достигается при d = (4, 13)/√185. Проверка разностью при t = 0.001 даёт ≈ 12.806.

Поиграй

Тащи точку и конец зелёной стрелки d. Оранжевая стрелка — градиент. Справа производная по направлению как функция угла: максимум там, где d совпадает с ∇f, ноль — вдоль линии уровня.
