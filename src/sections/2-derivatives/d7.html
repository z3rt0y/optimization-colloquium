Гессиан (Hessian) дважды дифференцируемой функции f: ℝⁿ → ℝ — матрица вторых частных производных

∇²f(x) = [ ∂²f / ∂xᵢ∂xⱼ ]i, j = 1..n.

Эквивалентно (Renegar §1.3), это линейный оператор H(x), для которого ∇f(x + h) = ∇f(x) + H(x)h + o(‖h‖): «производная градиента». Для f ∈ C² гессиан симметричен.

Интуиция

Градиент говорит, куда наклонена поверхность; гессиан — как этот наклон меняется, то есть кривизну. Собственные векторы гессиана — главные направления изгиба, собственные значения — сила изгиба вдоль них: плюс — чаша, минус — купол.

Подробнее

  • Квадратичная модель (quadratic model, лекция 5, сл. 2): f(x + p) = f(x) + ∇f(x)ᵀp + ½pᵀ∇²f(x)p + o(‖p‖²). Её минимизирует метод Ньютона (№ 20).
  • Знакоопределённость гессиана (№ 10) классифицирует стационарные точки (№ 8) и выпуклость (№ 12, 13): ∇²f ⪰ 0 всюду ⇔ f выпукла (Renegar, Prop. 1.4.1).
  • У квадратичной f(x) = ½xᵀQx − bᵀx гессиан постоянен: ∇²f = Q. Его крайние собственные значения — это L и µ (№ 14, 13), их отношение — число обусловленности (№ 15).

В задачах и в коде

Для МНК f(w) = (1/2N)‖Xw − y‖² гессиан равен XᵀX/N (лекция 4, сл. 19). Если признаки в разных масштабах, его собственные значения различаются на порядки, и градиентный спуск ползёт. Стандартизация признаков это лечит:

import numpy as np

rng = np.random.default_rng(0)
x = np.column_stack([rng.normal(0, 1, 500), rng.normal(0, 100, 500)])
h = x.T @ x / len(x)
print(np.linalg.eigvalsh(h))
xs = (x - x.mean(axis=0)) / x.std(axis=0)
hs = xs.T @ xs / len(xs)
print(np.linalg.eigvalsh(hs))
# [ 1.0281 8845.9929] ← κ ≈ 8600 # [0.9947 1.0053] ← после стандартизации κ ≈ 1

Посчитай руками

Упражнение лекции 1, сл. 14: найди определитель гессиана f(x) = 3x₁² + 2x₁x₂² + 4x₂² в точке (1, 1).

Решение

∂²f/∂x₁² = 6, ∂²f/∂x₁∂x₂ = 4x₂, ∂²f/∂x₂² = 4x₁ + 8.

В точке (1, 1): ∇²f = [[6, 4], [4, 12]], det = 72 − 16 = 56.

Дополнительно: след 18, собственные значения 9 ± √(81 − 56) = 9 ± 5, то есть 4 и 14. Оба положительны, поэтому в этой точке гессиан ≻ 0.

Поиграй

Тащи точку: справа гессиан, его собственные значения и вывод о кривизне. Цветные отрезки в точке — собственные направления (синий — изгиб вверх, оранжевый — вниз). Пунктир — линии уровня квадратичной модели: рядом с точкой они повторяют настоящие.
