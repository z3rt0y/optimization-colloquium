Стационарная и седловая точки (stationary point and saddle point)

На коллоквиуме · 0.5 балла нажми, чтобы открыть

Точка x* — стационарная (stationary point), если ∇f(x*) = 0.

Стационарная точка x* — седловая (saddle point), если она не является ни локальным минимумом, ни локальным максимумом: в любой её окрестности есть точки с f(x) < f(x*) и точки с f(x) > f(x*). Достаточный признак: ∇²f(x*) знаконеопределён (есть собственные значения разных знаков).

Интуиция

Перевал между двумя вершинами или чипс Pringles: вдоль одной оси это минимум, вдоль другой — максимум. Градиент в точке нулевой, поэтому градиентный спуск, попав точно в седло, там и останется, а рядом с ним сильно замедляется.

Подробнее

  • Классификация стационарной точки по гессиану: ≻ 0 ⇒ строгий локальный минимум; ≺ 0 ⇒ строгий локальный максимум; знаконеопределён ⇒ седло; вырожден (есть нулевое собственное значение) ⇒ тест 2-го порядка ничего не решает. Пример: у x⁴ + y⁴ (минимум) и у x³ − 3xy² («обезьянье седло», monkey saddle) гессиан в нуле нулевой.
  • У выпуклой дифференцируемой f любая стационарная точка — глобальный минимум (лекция 2, сл. 3), сёдел нет.
  • Не путай с седловой точкой лагранжиана (№ 22, 24): там x минимизирует L, а λ максимизирует. Название то же, понятие другое.

В задачах и в коде

Ландшафты потерь нейросетей в больших размерностях содержат множество сёдел, и это одна из причин «застревания» обучения на плато. Чистый метод Ньютона притягивается к сёдлам и максимумам (лекция 5, сл. 8), поэтому на практике гессиан регуляризуют. Классификация по собственным значениям в Colab:

import numpy as np

def hess(p):
    return np.array([[1.0, 0.0], [0.0, -2 + 3 * p[1]**2]])

pts = [np.array([0.0, 0.0]), np.array([0.0, np.sqrt(2)]), np.array([0.0, -np.sqrt(2)])]
for p in pts:
    print(p, np.linalg.eigvalsh(hess(p)))
# [0. 0.] [-2. 1.] ← разные знаки: седло # [0. 1.41421356] [1. 4.] ← оба > 0: минимум # [0. -1.41421356] [1. 4.]

Посчитай руками

Функция из лекции 5: f(x, y) = ½x² − y² + ¼y⁴. Найди все стационарные точки и классифицируй их.

Решение

∇f = (x, −2y + y³) = 0 ⇒ x = 0, y(y² − 2) = 0 ⇒ y ∈ {0, ±√2}. ∇²f = diag(1, −2 + 3y²).

В (0, 0): diag(1, −2) знаконеопределён ⇒ седло, f = 0.

В (0, ±√2): diag(1, 4) ≻ 0 ⇒ строгие локальные минимумы, f = −2 + 1 = −1. Они же глобальные: f = ½x² + ¼(y² − 2)² − 1 ≥ −1.

Поиграй

Слева карта со стационарными точками, справа поверхность (вращай мышкой или пальцем). Поставь точку куда угодно: виджет скажет, стационарна ли она и что говорит гессиан. Кнопка притягивает к ближайшей стационарной точке.
