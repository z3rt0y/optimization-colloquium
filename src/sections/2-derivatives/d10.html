Положительно определённая и полуопределённая матрица (positive definite and positive semidefinite matrix)

Симметричная матрица A ∈ ℝⁿˣⁿ

  • положительно полуопределённая (positive semidefinite, A ⪰ 0), если xᵀAx ≥ 0 для всех x ∈ ℝⁿ;
  • положительно определённая (positive definite, A ≻ 0), если xᵀAx > 0 для всех x ≠ 0.

Эквивалентно (Renegar §1.1): все собственные значения λᵢ ≥ 0 (для ⪰ 0) или λᵢ > 0 (для ≻ 0).

Интуиция

Квадратичная форма q(x) = xᵀAx — поверхность над плоскостью. ≻ 0 — чаша, поднимающаяся в любом направлении; ⪰ 0 — чаша с плоским жёлобом (есть направление, где форма не растёт); знаконеопределённая — седло; отрицательно определённая — купол.

Подробнее

  • Критерий Сильвестра (Sylvester's criterion): A ≻ 0 ⇔ все ведущие (угловые) главные миноры положительны. Для [[a, b], [b, c]]: a > 0 и ac − b² > 0.
  • Ловушка: для ⪰ 0 не хватает неотрицательности ведущих миноров, нужны все главные миноры. Пример A = [[0, 0], [0, −1]]: ведущие миноры 0 и 0, но xᵀAx = −x₂² < 0 при x = (0, 1). В виджете есть кнопка с этим примером.
  • A ≻ 0 ⇒ A обратима и задаёт скалярное произведение ⟨u, v⟩A = uᵀAv (Renegar §1.1). A ⪰ 0 может быть вырожденной.
  • Запись A ⪰ µI означает λmin(A) ≥ µ. На этом языке формулируются сильная выпуклость ∇²f ⪰ µI (№ 13) и гладкость ∇²f ⪯ LI (№ 14).

В задачах и в коде

Ковариационные матрицы и матрицы Грама ядер всегда ⪰ 0. Гессиан ≻ 0 в стационарной точке гарантирует строгий минимум (№ 3). Ньютоновское направление — направление спуска, только если H ≻ 0 (№ 20). В Colab быстрее всего проверять разложением Холецкого (Cholesky): оно существует ровно для ≻ 0.

import numpy as np

a = np.array([[2.0, -1.0], [-1.0, 2.0]])
print(np.linalg.eigvalsh(a))
try:
    np.linalg.cholesky(a)
    print("PD")
except np.linalg.LinAlgError:
    print("not PD")
# [1. 3.] # PD

Посчитай руками

Определи знакоопределённость A = [[2, −1], [−1, 2]], B = [[1, 2], [2, 1]], C = [[1, 1], [1, 1]].

Решение

A: a = 2 > 0, det = 4 − 1 = 3 > 0 ⇒ A ≻ 0 (собственные значения 1 и 3). Напрямую: xᵀAx = 2x₁² − 2x₁x₂ + 2x₂² = x₁² + x₂² + (x₁ − x₂)² > 0 при x ≠ 0.

B: det = 1 − 4 = −3 < 0 ⇒ знаконеопределена (собственные значения 3 и −1). При x = (1, −1): xᵀBx = 1 − 4 + 1 = −2 < 0.

C: главные миноры 1, 1, 0 ≥ 0 ⇒ C ⪰ 0; det = 0 ⇒ не ≻ 0 (собственные значения 0 и 2). При x = (1, −1) форма равна 0.

Поиграй

Задай матрицу [[a, b], [b, c]] ползунками или кнопками. Синее — где форма положительна, оранжевое — где отрицательна, жирная линия — нулевой уровень. Справа та же поверхность в 3D, её можно вращать.
