Градиент через линейное приближение (gradient via the linear approximation)

Colab: напрямуюЛекция 1, сл. 13 · Лекция 3, сл. 4 · Renegar §1.2
На коллоквиуме · 0.5 балла нажми, чтобы открыть

Функция f дифференцируема в точке x, если существует вектор g ∈ ℝⁿ такой, что

f(x + h) = f(x) + ⟨g, h⟩ + o(‖h‖) при h → 0,   т.е.   limh→0 |f(x + h) − f(x) − ⟨g, h⟩| / ‖h‖ = 0.

Этот вектор называется градиентом (gradient) ∇f(x). В стандартном скалярном произведении ∇f(x) = (∂f/∂x₁, …, ∂f/∂xₙ)ᵀ. Функция y ↦ f(x) + ⟨∇f(x), y − x⟩ — линейное приближение (first-order approximation).

Интуиция

Если сильно приблизить гладкую поверхность, она выглядит как наклонная плоскость; градиент задаёт наклон этой плоскости. Ошибка линейного приближения убывает быстрее, чем ‖h‖: сдвинулся в 10 раз меньше — ошибка примерно в 100 раз меньше.

Подробнее

  • Смысл направления и длины (лекция 3, сл. 4; Renegar §1.2): ∇f(x) указывает направление наискорейшего роста, ‖∇f(x)‖ — скорость роста на единицу пути. Градиент перпендикулярен линии уровня.
  • Частные производные могут существовать и без дифференцируемости: у f = xy/(x² + y²), f(0, 0) = 0, обе частные в нуле равны 0, а функция там даже не непрерывна. Поэтому определяй градиент через линейное приближение, а не как «вектор частных производных».
  • Градиент зависит от скалярного произведения: в ⟨u, v⟩S = uᵀSv он равен S⁻¹∇f (Renegar, Prop. 1.2.2). Отсюда идея предобусловливания (preconditioning, лекция 3, сл. 5).

В задачах и в коде

Все методы первого порядка (№ 18) тратят итерацию на один градиент. В нейросетях его считает обратный проход автоматического дифференцирования (reverse-mode AD, backpropagation, лекция 3). Стандартная проверка своего градиента в Colab — сравнить с центральной разностью (gradient check):

import numpy as np

def f(x):
    return 3 * x[0]**2 + 2 * x[0] * x[1]**2 + 4 * x[1]**2

def grad(x):
    return np.array([6 * x[0] + 2 * x[1]**2, 4 * x[0] * x[1] + 8 * x[1]])

x = np.array([1.0, 1.0])
h = 1e-6
num = np.zeros(2)
for i in range(2):
    e = np.zeros(2)
    e[i] = h
    num[i] = (f(x + e) - f(x - e)) / (2 * h)
print(grad(x), num)
# [ 8. 12.] [ 8. 12.]

Посчитай руками

Для f(x) = 3x₁² + 2x₁x₂² + 4x₂² (функция из упражнения лекции 1) найди ∇f(1, 1) и проверь, что ошибка линейного приближения при h = (0.1, 0) и h = (0.01, 0) убывает быстрее ‖h‖.

Решение

∂f/∂x₁ = 6x₁ + 2x₂², ∂f/∂x₂ = 4x₁x₂ + 8x₂ ⇒ ∇f(1, 1) = (8, 12), f(1, 1) = 9.

h = (0.1, 0): f(1.1, 1) = 3.63 + 2.2 + 4 = 9.83, прогноз 9 + 8·0.1 = 9.8, ошибка 0.03, ошибка/‖h‖ = 0.3.

h = (0.01, 0): f = 9.0803, прогноз 9.08, ошибка 0.0003, ошибка/‖h‖ = 0.03. Отношение уменьшилось в 10 раз вместе с ‖h‖, то есть стремится к 0. Ошибка здесь ровно 3h₁²: по x₁ функция квадратична с коэффициентом 3.

Поиграй

Слева карта уровней: тащи точку x, задай направление h углом и его длину. Справа — срез функции вдоль h и касательная прямая. Таблица показывает, что ошибка/‖h‖ стремится к нулю.
