Градиентный спуск с постоянным шагом (gradient descent with a constant step)

Colab: напрямуюЛекция 3, сл. 6–16 · Лекция 4, сл. 2–4
На коллоквиуме · 0.5 балла нажми, чтобы открыть

Градиентный спуск с постоянным шагом (gradient descent with a constant step): при фиксированном α > 0 строим итерации

xₖ₊₁ = xₖ − α ∇f(xₖ),   k = 0, 1, 2, …

Одна итерация стоит одного вычисления градиента. Для L-гладкой f при 0 < α < 2/L каждый шаг уменьшает f, пока ∇f ≠ 0.

Интуиция

Идёшь вниз по склону, и длина шага пропорциональна крутизне. Слишком маленький α — ползёшь; слишком большой — перепрыгиваешь дно и раскачиваешься; больше 2/L — разлетаешься.

Подробнее

  • Безопасный шаг из леммы о спуске (лекция 3, сл. 8): f(x⁺) ≤ f(x) − α(1 − Lα/2)‖∇f‖²; при α ≤ 1/L: f(x⁺) ≤ f(x) − (α/2)‖∇f‖².
  • Квадратичная функция (лекция 3, сл. 9): ошибка eₖ = xₖ − x⋆ меняется как eₖ₊₁ = (I − αQ)eₖ, каждая собственная компонента умножается на 1 − αλᵢ. Сходимость ⇔ 0 < α < 2/λmax(Q). При 1 − αλ < 0 компонента меняет знак каждый шаг (колебания).
  • Скорости (лекция 3, сл. 13–15): выпуклая L-гладкая f — f(xₖ) − f⋆ ≤ L‖x₀ − x⋆‖²/(2k), сублинейно O(1/k); µ-сильно выпуклая или PL — (1 − µ/L)ᵏ, линейно (теорема билетов 1, 12, 16).
  • Остановка (лекция 3, сл. 12): ‖∇f(xₖ)‖ ≤ ε, плюс лимит итераций и проверка на NaN.

В задачах и в коде

Базовый алгоритм обучения моделей; SGD (лекция 4) — тот же спуск со стохастической оценкой градиента по мини-батчу. Полная реализация для МНК:

import numpy as np

rng = np.random.default_rng(0)
x = rng.normal(size=(200, 3))
w_true = np.array([1.0, -2.0, 0.5])
y = x @ w_true + 0.1 * rng.normal(size=200)

h = x.T @ x / len(x)
lip = np.linalg.eigvalsh(h).max()
alpha = 1 / lip
w = np.zeros(3)
for i in range(200):
    grad = h @ w - x.T @ y / len(x)
    w = w - alpha * grad
print(w)
# [ 0.9912 -2.0098 0.5055]

Посчитай руками

1) f(x) = 2x² (L = 4), x₀ = 1. Сделай два шага при α = 0.1, 0.25, 0.5, 0.6. 2) f = ½(x² + 10y²), x₀ = (10, 1), α = 1/L = 0.1. Найди x₁ и сравни f(x₁) с гарантией теоремы.

Решение

1) xₖ₊₁ = xₖ − α·4xₖ = (1 − 4α)xₖ. α = 0.1: множитель 0.6 ⇒ 0.6, 0.36, сходимость. α = 0.25 = 1/L: множитель 0 ⇒ сразу 0. α = 0.5 = 2/L: множитель −1 ⇒ −1, 1, −1, … — вечные колебания на границе. α = 0.6: множитель −1.4 ⇒ −1.4, 1.96 — расходимость.

2) ∇f = (x, 10y) = (10, 10) ⇒ x₁ = (10 − 1, 1 − 1) = (9, 0). f(x₀) = ½(100 + 10) = 55, f(x₁) = 40.5. Гарантия (1 − µ/L)·55 = 0.9·55 = 49.5 ≥ 40.5 ✓. Дальше x убывает всего в 0.9 раза за шаг: это цена κ = 10.

Поиграй

Нажми на карту, чтобы поставить старт, и запусти «Пуск». Меняй κ, поворот долины и шаг α (кнопки ставят 1/L, 2/(L + µ) и 2/L). Справа f(xₖ) − f⋆ в логарифмической шкале: прямая линия означает линейную сходимость, пунктир — гарантия теоремы.
