Метод Ньютона (ньютоновское направление) (Newton's method, Newton direction)

Ньютоновское направление (Newton direction) pN в точке x — решение линейной системы (гессиан обратим)

∇²f(x) · pN = −∇f(x).

Метод Ньютона: xₖ₊₁ = xₖ + pN(xₖ) = xₖ − [∇²f(xₖ)]⁻¹∇f(xₖ). При ∇²f(x) ≻ 0 точка x + pN — минимум квадратичной модели m(p) = f(x) + ∇f(x)ᵀp + ½pᵀ∇²f(x)p (Renegar §1.6).

Интуиция

В текущей точке строим параболу (квадратичную модель), касающуюся f до второго порядка, и прыгаем в её вершину. Для квадратичной функции модель совпадает с f, и хватает одного шага.

Подробнее

  • Один шаг на квадратичной (лекция 5, сл. 5): для f = ½xᵀQx − bᵀx + c, Q ≻ 0, из любой точки x + pN = Q⁻¹b = x⋆.
  • Локальная квадратичная сходимость (теорема билетов 5, 10; лекция 5, сл. 6–7): если ∇f(x⋆) = 0, ∇²f(x⋆) ≻ 0, гессиан M-липшицев и рядом с x⋆ ‖∇²f(x)⁻¹‖ ≤ 1/m, то ‖x⁺ − x⋆‖ ≤ (M/2m)‖x − x⋆‖². Число верных знаков примерно удваивается каждую итерацию.
  • Геометрия (лекция 5, сл. 4; Renegar §1.6): GD использует «круглую» метрику, Ньютон — метрику гессиана. Ньютоновский шаг не зависит от выбора скалярного произведения, поэтому метод нечувствителен к числу обусловленности.
  • Где ломается (лекция 5, сл. 8–9): знаконеопределённый H — шаг может вести вверх или к седлу; вырожденный H; старт далеко — шаг выходит из области, где модель верна. Лечат демпфированием по Армихо (damped Newton, сл. 10) и регуляризацией (H + λI)p = −g (сл. 11).
  • Цена (сл. 12): факторизация гессиана O(n³), память O(n²). Матрицу H⁻¹ явно не считают, решают систему.

В задачах и в коде

Логистическая регрессия и обобщённые линейные модели (IRLS — это метод Ньютона), solver="newton-cg" в sklearn, финальное уточнение решения в задачах умеренной размерности. Для больших моделей — квазиньютоновские BFGS и L-BFGS (лекция 5).

import numpy as np

x = 0.0
for i in range(6):
    g = np.exp(x) - 2
    h = np.exp(x)
    x = x - g / h
    print(i + 1, x, abs(x - np.log(2)))
# 1 1.0 0.307 # 2 0.735759 0.0426 # 3 0.694042 0.000895 # 4 0.693148 4.0e-07 # 5 0.693147 8.0e-14 ← число верных знаков удваивается

Посчитай руками

1) Метод Ньютона для f(x) = eˣ − 2x из x₀ = 0. 2) Шаг Ньютона для f(x, y) = x² + xy + y² − 3x из (0, 0). 3) Пример лекции 5: f = ½x² − y² + ¼y⁴ в точке (0, 0.5). Найди pN и проверь, спуск ли это.

Решение

1) f′ = eˣ − 2, f″ = eˣ, xₖ₊₁ = xₖ − (e^{xₖ} − 2)/e^{xₖ} = xₖ − 1 + 2e^{−xₖ}. x₁ = 1, x₂ = 2/e ≈ 0.7358, x₃ ≈ 0.69404, x₄ ≈ 0.6931476; x⋆ = ln 2 ≈ 0.6931472. Ошибки: 0.31 → 0.043 → 9·10⁻⁴ → 4·10⁻⁷ → 8·10⁻¹⁴.

2) ∇f(0, 0) = (−3, 0), H = [[2, 1], [1, 2]]. Решаем Hp = (3, 0): p = (2, −1) ⇒ x₁ = (2, −1) = x⋆ (№ 3) за один шаг, потому что функция квадратичная.

3) g = (0, −2·0.5 + 0.125) = (0, −0.875), H = diag(1, −1.25). pN = −H⁻¹g = (0, −0.7). gᵀpN = 0.6125 > 0 — это направление подъёма: гессиан знаконеопределён.

Поиграй

Оранжевая парабола — квадратичная модель в текущей точке, её вершина — следующая итерация. Попробуй √(1 + x²): из x₀ = 0.9 метод сходится, из 1.1 разлетается (x⁺ = −x³). На x⁴ − 3x² + x модель может смотреть вниз; включи демпфирование и регуляризацию.
