Условие Армихо (бэктрекинг) (Armijo condition, backtracking)

Условие Армихо (Armijo condition, условие достаточного убывания, sufficient decrease) для направления спуска d:

f(x + αd) ≤ f(x) + c·α·∇f(x)ᵀd,   c ∈ (0, 1).

Бэктрекинг (backtracking): выбрать α₀ > 0, β ∈ (0, 1); начиная с α = α₀, повторять α ← βα, пока условие не выполнится. Для GD (d = −∇f): f(x − α∇f) ≤ f(x) − cα‖∇f(x)‖². Типично β = 1/2, c = 10⁻⁴.

Интуиция

Касательная из точки (0, f(x)) — обещание линейной модели. Армихо требует получить хотя бы долю c от обещанного убывания. Начинаем с большого шага и укорачиваем его, пока функция не окажется под «пологой» прямой с наклоном c·φ′(0).

Подробнее

  • Бэктрекинг заканчивается (лекция 3, сл. 11): если ∇f L-липшицев и d = −∇f ≠ 0, условие выполнено при всех α ≤ 2(1 − c)/L, а βʲα₀ → 0, так что за конечное число шагов α попадёт в этот интервал.
  • Зачем c < 1: при c = 1 пришлось бы лечь ниже касательной, а для выпуклой функции это невозможно. Маленькое c делает условие мягким.
  • Само условие допускает слишком короткие шаги; бэктрекинг борется с этим, начиная с большого α₀. Квазиньютоновские методы добавляют условие кривизны Вольфе (Wolfe curvature condition, лекция 5, сл. 19).
  • В демпфированном методе Ньютона (лекция 5, сл. 10) пробуют α = 1, β, β², …; вблизи решения принимается полный шаг α = 1, и квадратичная сходимость сохраняется.

В задачах и в коде

Нужен, когда L неизвестна или сильно меняется по пространству, то есть почти всегда на практике. Линейный поиск с условием Армихо встроен в scipy.optimize и в большинство солверов. Свой бэктрекинг — несколько строк:

import numpy as np

def backtracking(f, grad_x, x, d, alpha0=1.0, beta=0.5, c=1e-4):
    alpha = alpha0
    fx = f(x)
    slope = grad_x @ d
    while f(x + alpha * d) > fx + c * alpha * slope:
        alpha = beta * alpha
    return alpha

def f(x):
    return 0.5 * (x[0]**2 + 10 * x[1]**2)

x = np.array([1.0, 1.0])
g = np.array([x[0], 10 * x[1]])
print(backtracking(f, g, x, -g))
# 0.125 ← первый шаг из 1, 0.5, 0.25, … не больше 2(1 − c)/L ≈ 0.2

Посчитай руками

f(x) = x², x = 1, d = −f′(1) = −2, α₀ = 1, β = ½. Проведи бэктрекинг для c = ½ и c = 10⁻⁴.

Решение

φ(α) = f(1 − 2α) = (1 − 2α)², φ(0) = 1, φ′(0) = f′(1)·d = −4.

c = ½: правая часть 1 − 2α. α = 1: φ = 1 > −1 ✗. α = 0.5: φ = 0 ≤ 0 ✓ ⇒ α = 0.5, это и есть точный минимум, x⁺ = 0.

c = 10⁻⁴: правая часть 1 − 0.0004α. α = 1: φ = 1 > 0.9996 ✗ (x⁺ = −1, f не уменьшилась). α = 0.5: 0 ≤ 0.9998 ✓. Сверка с теорией: L = 2, гарантированный интервал α ≤ 2(1 − 10⁻⁴)/2 = 0.9999; шаг α = 1 лежит чуть за его границей.

Поиграй

График функции вдоль антиградиента φ(α) = f(x − α∇f), касательная (пунктир) и прямая Армихо. Подсвеченный участок оси — шаги, проходящие проверку. «Запустить бэктрекинг» показывает пробы α₀, βα₀, β²α₀, …

Поиграй в 3D: бэктрекинг на поверхности

Поверхность z = f(x₁, x₂) с линиями уровня под ней. Из x₀ идёт направление спуска (descent direction) d = −∇f(x₀); вертикальная плоскость вдоль d режет поверхность по кривой φ(α) = f(x₀ + αd) — это та же кривая, что на 2D-графике выше. В плоскости лежат касательная и прямая Армихо, пробы бэктрекинга (backtracking) отмечены на кривой.
