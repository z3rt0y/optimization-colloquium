Направление спуска (descent direction)

Вектор d — (строгое) направление спуска (descent direction) функции f в точке x, если

∇f(x)ᵀd < 0.

Тогда для дифференцируемой f: f(x + αd) < f(x) при всех достаточно малых α > 0.

Интуиция

Направление образует с антиградиентом острый угол (меньше 90°): шагнёшь немного — функция уменьшится. Это не обязательно сам антиградиент, подходит любое направление «в нижнюю полуплоскость».

Подробнее

  • Почему так: f(x + αd) = f(x) + α∇f(x)ᵀd + o(α); при малом α главный член α∇fᵀd < 0 перевешивает o(α).
  • Примеры: −∇f(x) (наискорейший спуск, steepest descent, в евклидовой норме); −M⁻¹∇f(x) для любой M ≻ 0 (предобусловленный GD, Ньютон при H ≻ 0, BFGS при G ≻ 0); −∂ᵢf(x)·eᵢ (покоординатный спуск, лекция 4).
  • Ньютоновское направление при знаконеопределённом гессиане может вести вверх: в примере лекции 5, сл. 9 ∇fᵀpN = 0.6125 > 0. Линейный поиск такое направление не исправит.
  • Если ∇f(x) = 0, направлений спуска первого порядка нет.

В задачах и в коде

Все методы линейного поиска строятся по шаблону лекции 3: выбрать направление dₖ, потом шаг αₖ, потом проверить остановку. Правило Армихо (№ 19) имеет смысл только для направления спуска, поэтому знак ∇fᵀd проверяют до линейного поиска.

import numpy as np

grad = np.array([2.0, 8.0])
for d in [np.array([-1.0, 0.0]), np.array([1.0, -1.0]), np.array([-1.0, 1.0])]:
    slope = grad @ d
    print(d, slope, slope < 0)
# [-1. 0.] -2.0 True # [ 1. -1.] -6.0 True # [-1. 1.] 6.0 False

Посчитай руками

f(x, y) = x² + 4y², точка (1, 1). Какие из d₁ = (−1, 0), d₂ = (1, −1), d₃ = (−1, 1) — направления спуска?

Решение

∇f = (2x, 8y) = (2, 8). d₁: −2 < 0 ✓. d₂: 2 − 8 = −6 < 0 ✓, хотя x при этом растёт; проверка: f(1.1, 0.9) = 1.21 + 3.24 = 4.45 < f(1, 1) = 5. d₃: −2 + 8 = 6 > 0 ✗, это направление подъёма.

Поиграй

Тащи точку и конец стрелки d. Зелёный полукруг — все направления спуска (угол с −∇f меньше 90°), граница — касательная к линии уровня. Справа функция вдоль луча φ(α) = f(x + αd) и её наклон в нуле.
