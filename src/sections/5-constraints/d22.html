Лагранжиан (Lagrangian)

Colab: для проверкиЛекция 2 (вторая часть) · Boyd & Vandenberghe §5.1
На коллоквиуме · 0.5 балла нажми, чтобы открыть

Для задачи min f(x) при gᵢ(x) ≤ 0 (i = 1..m), hⱼ(x) = 0 (j = 1..p) лагранжиан (Lagrangian) — функция

L(x, λ, ν) = f(x) + Σᵢ λᵢ gᵢ(x) + Σⱼ νⱼ hⱼ(x),

где λ ∈ ℝᵐ и ν ∈ ℝᵖ — множители Лагранжа (Lagrange multipliers), они же двойственные переменные (dual variables). Для неравенств берут λᵢ ≥ 0, знак νⱼ любой.

Интуиция

Жёсткие ограничения заменяем штрафами-ценами: λᵢ — цена за единицу нарушения i-го ограничения. Если x допустима и λ ≥ 0, каждое слагаемое λᵢgᵢ(x) ≤ 0, поэтому L(x, λ, ν) ≤ f(x): на допустимых точках лагранжиан — «оптимистичная» оценка цели.

Подробнее

  • Максимум по множителям возвращает исходную задачу: supλ≥0, ν L(x, λ, ν) = f(x), если x допустима, и +∞ иначе. Поэтому p⋆ = infx supλ≥0, ν L. Если поменять inf и sup местами, получится двойственная задача (№ 24).
  • Стационарность лагранжиана ∇ₓL = 0 — первое из условий ККТ (№ 23). Для задачи только с равенствами это классический метод множителей Лагранжа: ∇ₓL = 0, h(x) = 0.
  • Множители — чувствительности (sensitivity, лекция 2, сл. 2): если ограничение gᵢ(x) ≤ 0 ослабить до gᵢ(x) ≤ δ, оптимальное значение изменится примерно на −λᵢ⋆δ. В задаче P: p⋆(δ) = (2 − δ)²/2, производная в нуле −2 = −λ₁⋆. Экономисты называют это теневой ценой (shadow price).
  • Седловая точка лагранжиана (x⋆, λ⋆): x⋆ минимизирует L(·, λ⋆), λ⋆ максимизирует L(x⋆, ·) по λ ≥ 0. Не путай с седлом функции (№ 8).

В задачах и в коде

Регуляризация как ограничение: ridge min ‖Xw − y‖² + λ‖w‖² — лагранжиан задачи с ограничением ‖w‖² ≤ t. Двойственная задача SVM, ограничения справедливости (fairness) в ML, теневые цены в экономике. Систему ∇L = 0 можно решить символьно:

import sympy as sp

x1 = sp.symbols("x1")
x2 = sp.symbols("x2")
lam = sp.symbols("lam")
f = (x1 - 3)**2 + (x2 - 2)**2
g = x1 + x2 - 3
lagr = f + lam * g
eqs = [sp.diff(lagr, x1), sp.diff(lagr, x2), g]
print(sp.solve(eqs, [x1, x2, lam], dict=True))
# [{lam: 2, x1: 2, x2: 1}]

Посчитай руками

1) min x² + y² при x + y = 1 методом множителей Лагранжа. 2) Выпиши лагранжиан задачи P (№ 21) и найди его минимум по x при фиксированном λ₁ (λ₂ = λ₃ = 0).

Решение

1) L = x² + y² + ν(x + y − 1). ∂L/∂x = 2x + ν = 0, ∂L/∂y = 2y + ν = 0 ⇒ x = y = −ν/2. Из x + y = 1: ν = −1, x = y = ½, f⋆ = ½. Отрицательный ν для равенства — норма.

2) L = (x₁ − 3)² + (x₂ − 2)² + λ₁(x₁ + x₂ − 3) − λ₂x₁ − λ₃x₂. При λ₂ = λ₃ = 0: ∂L/∂x₁ = 2(x₁ − 3) + λ₁ = 0 ⇒ x₁ = 3 − λ₁/2, аналогично x₂ = 2 − λ₁/2. При λ₁ = 2 получаем (2, 1) — решение задачи P.

Поиграй

Задача min x² при x ≥ b. Серая парабола — f, синяя — лагранжиан L(x, λ) = x² + λ(b − x). На допустимой зоне (x ≥ b) синяя кривая всегда ниже серой. Подбирай λ: при λ = λ⋆ минимум лагранжиана попадает ровно в решение задачи.
