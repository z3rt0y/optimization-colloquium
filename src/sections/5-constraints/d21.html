Активное ограничение (active constraint)

Colab: напрямуюЛекция 2 (вторая часть) · Nocedal & Wright, опр. 12.1
На коллоквиуме · 0.5 балла нажми, чтобы открыть

Рассмотрим задачу с ограничениями-неравенствами gᵢ(x) ≤ 0. Ограничение i активно (active constraint) в допустимой точке x, если

gᵢ(x) = 0,

и неактивно, если gᵢ(x) < 0. Множество активных ограничений (active set) A(x) = {i : gᵢ(x) = 0}. Ограничения-равенства hⱼ(x) = 0 в допустимой точке активны всегда.

Интуиция

Активное ограничение — стенка, в которую ты упёрся. Неактивное — стенка где-то вдали: если чуть пошевелиться, ты её не почувствуешь. Локально важны только активные.

Подробнее

  • Неактивные ограничения можно выбросить, и x⋆ останется локальным минимумом: в малой окрестности они выполняются автоматически (по непрерывности gᵢ).
  • Дополняющая нежёсткость в ККТ (№ 23): λᵢgᵢ(x⋆) = 0 ⇒ у неактивных ограничений λᵢ = 0. Ненулевые множители бывают только у активных.
  • Допустимые направления многогранника (№ 9) определяются только активными ограничениями: aᵢᵀd ≤ 0 для i ∈ A(x).
  • Если бы активное множество в x⋆ было известно заранее, неравенства превратились бы в равенства. На этом построены методы активного множества (active-set methods) для QP.
  • В численном коде «активно» проверяют с допуском: |gᵢ(x)| ≤ ε.

В задачах и в коде

SVM: опорные векторы (support vectors) — ровно те объекты, у которых ограничение yᵢ(wᵀxᵢ + b) ≥ 1 активно; остальные объекты на решение не влияют. Бюджетное ограничение в портфеле активно (binding), если весь бюджет израсходован. В L-BFGS-B переменные, прижатые к границе ящика, — активные ограничения (лекция 5, сл. 22).

import numpy as np

a = np.array([[1.0, 1.0], [-1.0, 0.0], [0.0, -1.0]])
b = np.array([3.0, 0.0, 0.0])
x = np.array([2.0, 1.0])
slack = a @ x - b
active = np.where(np.abs(slack) < 1e-9)[0]
print(slack, active)
# [ 0. -2. -1.] [0] ← активно только первое ограничение

Посчитай руками

Задача P (она же в № 22–24): min (x₁ − 3)² + (x₂ − 2)² при g₁ = x₁ + x₂ − 3 ≤ 0, g₂ = −x₁ ≤ 0, g₃ = −x₂ ≤ 0. Определи активные ограничения в точках (2, 1), (0, 0), (0, 3), (1, 1).

Решение

(2, 1): g = (0, −2, −1) ⇒ A = {1}. (0, 0): g = (−3, 0, 0) ⇒ A = {2, 3}. (0, 3): g = (0, 0, −3) ⇒ A = {1, 2} (вершина). (1, 1): g = (−1, −1, −1) ⇒ A = ∅, внутренняя точка.

Точка (2, 1) — решение задачи P; это проверяется в № 23.
