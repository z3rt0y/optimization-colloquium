Двойственная функция и двойственная задача (dual function and dual problem)

Двойственная функция (Lagrange dual function):

q(λ, ν) = infx L(x, λ, ν) = infx [ f(x) + Σᵢ λᵢgᵢ(x) + Σⱼ νⱼhⱼ(x) ].

Инфимум берётся по всей области определения, а не только по допустимым x, и может равняться −∞. В Boyd & Vandenberghe она обозначена g(λ, ν).

Двойственная задача (dual problem): max q(λ, ν) при λ ≥ 0. Её оптимум d⋆ ≤ p⋆ (слабая двойственность, weak duality).

Интуиция

Каждый набор цен λ ≥ 0 даёт нижнюю оценку ответа исходной задачи. Двойственная задача ищет лучшую, то есть самую высокую нижнюю оценку. Если она совпала с найденным значением, решение доказанно оптимально.

Подробнее

  • q всегда вогнута (concave), даже если исходная задача невыпукла: это инфимум семейства аффинных по (λ, ν) функций. Поэтому двойственная задача всегда выпуклая.
  • Слабая двойственность в одну строку: для допустимого x̃ и λ ≥ 0: q(λ, ν) ≤ L(x̃, λ, ν) = f(x̃) + Σλᵢgᵢ(x̃) + 0 ≤ f(x̃); берём inf по допустимым x̃ ⇒ q ≤ p⋆.
  • Зазор двойственности (duality gap) p⋆ − d⋆ ≥ 0. Сильная двойственность d⋆ = p⋆ выполняется для выпуклых задач при условии Слейтера, а для LP — всегда, если оптимум конечен (двойственность LP есть в книге Korte & Vygen).
  • В невыпуклых задачах зазор бывает: для min −x² при −1 ≤ x ≤ 1 лагранжиан не ограничен снизу по x, q ≡ −∞, а p⋆ = −1.

В задачах и в коде

Двойственная задача SVM даёт kernel trick; лагранжева релаксация в комбинаторной оптимизации даёт нижние оценки (Korte & Vygen); зазор двойственности — стандартный критерий остановки солверов, включая методы внутренней точки из Renegar. Двойственную функцию задачи P можно найти численно, минимизируя L по сетке:

import numpy as np

g1 = np.linspace(-2, 6, 401)
grid = np.meshgrid(g1, g1)
x1 = grid[0]
x2 = grid[1]
for lam in [0.0, 1.0, 2.0, 3.0]:
    lagr = (x1 - 3)**2 + (x2 - 2)**2 + lam * (x1 + x2 - 3)
    print(lam, lagr.min())
# 0.0 0.0 1.0 1.5 2.0 2.0 3.0 1.5 ← все ≤ p⋆ = 2, максимум при λ = 2

Посчитай руками

1) Найди q(λ) и реши двойственную задачу для P, оставив только ограничение g₁ (остальные в оптимуме неактивны). 2) min x при x ≥ 1: найди q(λ).

Решение

1) Из № 22: x₁ = 3 − λ/2, x₂ = 2 − λ/2. Подставляем: q(λ) = λ²/4 + λ²/4 + λ(5 − λ − 3) = 2λ − λ²/2. q′ = 2 − λ = 0 ⇒ λ⋆ = 2, d⋆ = 4 − 2 = 2 = p⋆: сильная двойственность (Слейтер: точка (0.5, 0.5) строго допустима). Слабая двойственность в числах: q(1) = 1.5 ≤ 2, q(3) = 1.5 ≤ 2, q(4) = 0 ≤ 2.

2) L = x + λ(1 − x) = (1 − λ)x + λ. Инфимум по x ∈ ℝ равен −∞ при λ ≠ 1 и равен 1 при λ = 1. Значит q(1) = 1, иначе −∞, и d⋆ = 1 = p⋆. Так двойственная функция «прячет» ограничения в то, где она конечна.

Поиграй

Вогнутая кривая — двойственная функция q(λ), зелёная линия — p⋆. При любом λ кривая не выше линии (слабая двойственность), а её максимум касается линии (сильная двойственность для выпуклой задачи). Меняй параметр задачи и λ.
