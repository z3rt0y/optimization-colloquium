Условия Каруша–Куна–Таккера (Karush–Kuhn–Tucker (KKT) conditions)

Для задачи min f(x) при gᵢ(x) ≤ 0, hⱼ(x) = 0 с дифференцируемыми f, gᵢ, hⱼ тройка (x⋆, λ⋆, ν⋆) удовлетворяет условиям ККТ (KKT conditions), если:

  1. стационарность (stationarity): ∇f(x⋆) + Σᵢ λᵢ⋆∇gᵢ(x⋆) + Σⱼ νⱼ⋆∇hⱼ(x⋆) = 0;
  2. допустимость прямой задачи (primal feasibility): gᵢ(x⋆) ≤ 0, hⱼ(x⋆) = 0;
  3. допустимость двойственной задачи (dual feasibility): λᵢ⋆ ≥ 0;
  4. дополняющая нежёсткость (complementary slackness): λᵢ⋆ gᵢ(x⋆) = 0 для всех i.

Интуиция

Равновесие сил. Целевая функция тянет x в сторону −∇f, активные стенки отталкивают внутрь с силами −λᵢ∇gᵢ (∇gᵢ смотрит наружу), и в оптимуме силы уравновешены: −∇f − Σλᵢ∇gᵢ = 0. Стенка может только толкать (λ ≥ 0), и толкает лишь та, которой касаешься (λᵢ = 0 у неактивных).

Подробнее

  • Достаточность (теорема билетов 6, 7, 9): если f и gᵢ выпуклы, hⱼ аффинны и (x⋆, λ⋆, ν⋆) удовлетворяет ККТ, то x⋆ — глобальный минимум. Идея: x⋆ минимизирует выпуклую по x функцию L(·, λ⋆, ν⋆), а на допустимых x выполнено L ≤ f и L(x⋆, λ⋆, ν⋆) = f(x⋆).
  • Необходимость требует условий регулярности (constraint qualification): LICQ — градиенты активных ограничений линейно независимы; для выпуклых задач — условие Слейтера (Slater: существует строго допустимая точка). Тогда в любом локальном минимуме найдутся множители, удовлетворяющие ККТ.
  • Без выпуклости ККТ дают только список кандидатов, как условие ∇f = 0 в безусловной задаче.
  • Отрицательный множитель — сигнал, что от этой стенки выгодно отойти внутрь и точка не оптимальна.
  • Без ограничений ККТ сводятся к ∇f(x⋆) = 0.

В задачах и в коде

Аналитические решения (water-filling, проекция на симплекс), опорные векторы SVM, проверка ответа солвера. cvxpy возвращает множители в constraint.dual_value, так что ККТ можно проверить руками (если пакета нет в Colab: pip install cvxpy):

import numpy as np
import cvxpy as cp

x = cp.Variable(2)
constraints = [x[0] + x[1] <= 3, x >= 0]
target = np.array([3.0, 2.0])
prob = cp.Problem(cp.Minimize(cp.sum_squares(x - target)), constraints)
prob.solve()
print(x.value, prob.value, constraints[0].dual_value, constraints[1].dual_value)
# [2. 1.] 2.0 2.0 [0. 0.] ← λ₁ = 2, у неактивных x ≥ 0 множители 0

Посчитай руками

Проверь ККТ для задачи P (№ 21) в точках (2, 1) и (0, 0).

Решение

∇f = (2(x₁ − 3), 2(x₂ − 2)), ∇g₁ = (1, 1), ∇g₂ = (−1, 0), ∇g₃ = (0, −1).

Точка (2, 1): активно только g₁ ⇒ λ₂ = λ₃ = 0. Стационарность: (−2, −2) + λ₁(1, 1) = 0 ⇒ λ₁ = 2 ≥ 0 ✓. Допустимость ✓, дополняющая нежёсткость λ₁g₁ = 2·0 = 0 ✓. Задача выпуклая ⇒ по теореме достаточности (2, 1) — глобальный минимум, f⋆ = 2.

Точка (0, 0): активны g₂, g₃, λ₁ = 0. (−6, −4) + λ₂(−1, 0) + λ₃(0, −1) = 0 ⇒ λ₂ = −6, λ₃ = −4 < 0 ✗. Двойственная допустимость нарушена: обе стенки «тянут», а не толкают, значит от них выгодно отойти внутрь.

Поиграй

Режим «оптимум»: тащи оранжевый центр цели, решение x⋆ и множители пересчитываются; оранжевая стрелка −∇f уравновешена фиолетовыми силами стенок −λᵢ∇gᵢ. Режим «проверить точку»: ставь любую точку и смотри, какое из четырёх условий нарушено.
