Блок 4 · выпуклость: когда локальный = глобальный

№ПонятиеФормулаОткуда
16Выпуклая комбинация (convex combination) № 11Σ θᵢxᵢ,  θᵢ ≥ 0,  Σ θᵢ = 1взвешенное среднее, центр масс

19Строго выпуклая (strictly convex) № 13то же с < при x ≠ y, t ∈ (0, 1)из 18, как 4 из 3. Минимум (если есть) единственный

Блок 5 · кривизна сверху и PL

№ПонятиеФормулаОткуда
21L-гладкость (L-smooth) № 14 · Т4‖∇f(x) − ∇f(y)‖ ≤ L‖x − y‖зеркало 20: там изгиб снизу ≥ µ, тут сверху ≤ L. Для f ∈ C²: ⇔ ‖H‖ ≤ L, то есть −LI ⪯ H ⪯ LI; для выпуклой f это H ⪯ LI (λmax ≤ L). Следствие (лемма о спуске): f(y) ≤ f(x) + ∇fᵀ(y − x) + (L/2)‖y − x‖²
Уточнено. Для невыпуклой f одного λmax ≤ L мало: нужно L = max|λ| (см. П8, запись 5).
22Число обусловленности (condition number) № 15κ = L/µ ≥ 1отношение верхней границы к нижней; для квадратичной λmax/λmin = cond(Q)
23Условие PL (Polyak–Łojasiewicz) № 16½‖∇f(x)‖² ≥ µ(f(x) − f⋆)в касательной форме 20 минимизируем правую часть по y: y = x − (1/µ)∇f, получаем f⋆ ≥ f(x) − ‖∇f‖²/(2µ). Объявили это определением и выкинули выпуклость
